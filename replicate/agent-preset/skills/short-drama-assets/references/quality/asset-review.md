# 资产审核

本文件是资产阶段审核判定的唯一所有者。输入为可唯一识别的候选资产清单、参考图／参考音频绑定、原剧本、审核通过的分析与故事交付及导演确认结论；输出为绑定候选版本的事实覆盖、缺陷账本和审核结论。审核只验证和定位，不在遍历中顺手补造资产。

## 审核门

1. **剧情事实覆盖**：本集出场人物、时期状态、场景、道具、音频和故事稿新增的环境／功能分组均有对应资产或明确记录为不需要固定资产；资产名称、称谓和首次可见范围不提前泄露原文未揭示信息。
2. **身份与身体拓扑**：人物固定可见特征、年龄／身份阶段、非人或复杂身体的拓扑锁、固定肢体数量、连接来源、允许变化与禁止漂移均有原文或导演确认依据；参考图不能证明未被看见的结构，生成结果不能反向成为唯一身份依据。
3. **时期与连续状态**：换装、成长、变身、伤势、身份变化和道具功能阶段均区分共用身份锚点、本期状态、合法变化及不可继承状态；普通时间跳跃不被错误建成连续变形。
4. **参考职责与绑定**：每张参考图／参考音频标明职责、视角、使用范围和确认状态；正面、侧面、背面、空间基准全景、补充视图和编辑目标不互相越权。未确认候选不得写入正式绑定或提示词引用。
5. **声音身份**：重复有对白人物使用已确认的固定参考音频或明确的场次音频映射；情绪、语速、停顿和呼吸留给场次表演，不伪造文字音色描述；音频冲突保持待确认。
6. **空间与动作可用性**：复杂场景的空间基准全景、区域与通道、门窗／楼梯／隔断、道具方位、人物进出和追逐路径能支撑故事稿与提示词中的起点、路径、终点、遮挡和受力动作；简单场景不因形式要求虚增参考图。
7. **下游投影**：每项正式资产都能映射到使用场次、镜头职责、持有人／出镜组、初始状态和允许变化；故事稿中的新增环境运行、装备状态和功能人员不得只停留在附录。未确认资产不得进入正式提示词、当前状态入口或网站提交清单。

## 缺陷账本与状态

先列 `新增或变更资产｜原文／分析／故事或导演依据｜使用范围｜确认状态｜判定`，覆盖本轮候选清单的每一项。实际缺陷记录：`AS-编号｜失败／警告／建议｜资产或绑定定位｜权威依据｜问题｜影响镜头／阶段｜修正目标｜状态`。以下为失败：身份或拓扑无依据、时期状态混用、参考职责冲突、声音身份被文字臆造、空间基准与动作路径不一致、资产无法映射下游，或未确认内容已进入正式绑定。重复资产、参考图数量或展示风格只在影响连续性或交付时成为失败；纯效率或审美优化为建议。

状态只使用 `候选`、`待导演确认`、`已修正待复审`、`审核通过`、`审核失败`。失败不得升级；警告须保留原因、影响和处理结论，涉及创作选择或授权边界须经导演确认。

## 修正与复审

1. 锁定候选资产清单、参考绑定和版本，完成七道审核门并先登记全部缺陷。
2. 可见字段遗漏、引用错误、范围标记、文件映射和连续性账本等执行性缺陷可在授权内自动修正；涉及人物身份／能力、身体拓扑、时期状态、空间基准、声音身份、新资产职责或参考图取舍时暂停请导演确认。
3. 每项修正关闭对应缺陷后，重新执行事实覆盖、拓扑、时期、参考职责、声音、空间和下游投影的全量复审，不设固定轮次；不得用替代候选掩盖失败。
4. 零失败且所有警告均有处理结论时报告“审核通过”，并将资产版本、参考职责、确认记录和审核报告写入当前项目；否则保持“审核失败”或“待导演确认”。
5. 只有审核通过的资产包、参考图和参考音频绑定，才能被提示词技能读取为正式输入；候选、历史和修复中版本保留但不作为默认资产。
