# Seedance／即梦适配器

本文件只保存工具特有字段；通用剧情、资产、音频、镜头、时长和输出规则由模块与紧凑模板提供。

## 工具字段

- 整集词头增加 `工具：<Seedance／即梦具体版本>`；未提供版本时只写已知工具名，不猜测版本。
- 固定人物统一使用 `<人物名称>：形象参考：@imageN，面部参考：@imageN，声音参考：@音频N；` 建立稳定映射，不在人物引用后追加形象描写。
- 固定场景、无参考重复场景和临时场景统一使用 `<场景名称>：场景参考：@image<编号>；`；固定道具和无参考重复道具统一使用 `<道具名称>：道具参考：@image<编号>；`。未绑定时保留模板占位符但不虚构实际编号，引用后不追加固定外观描写。
- 当前时段和天气写入场景总体状态；人物与道具的初始位置、朝向、距离、持有人、持握／接触和状态写入初始空间状态；路径、变化和交接只写入实际发生的逐镜动作。
- 三视图分为多个输入时按摄影机观察方向调用最接近视角；三视图合并在一张图时写明其中包含的视角，但不虚构独立编号。
- 参考音频由项目或工具输入层直接绑定，并在统一词头的人物引用行用 `声音参考：@音频N` 指向已绑定输入；不写文件路径或文字音色，只写当前对白的情绪、音量、语速、停顿、重音和呼吸。

## 复制边界

- 每次提交由完整词头、单一初始空间状态段落及当前生成段镜头提示词组成。词头固定使用 `【第<集数>集统一词头·严格锁定】`，按地域与类型及摄影风格、项目场景总体状态与美术限制、声音与文字边界、人物参考、道具参考、场景参考、初始空间状态排列；每段完整保留结构，只填写该段实际需要的资产，不得写“同上”。
- 制作参考、旁白、对应原文、检查报告及长镜头自审／授权信息不提交模型。
- 每个生成段仍须自包含本段实际使用的资产名；资产引用后的段落只记录人物和道具进入本段时同时成立的初始空间状态。动态位置、声音、段间变化、禁项和承接在实际相关的逐镜描述或制作参考中处理。
- 生成段时间轴从0.0秒开始，镜头合计等于段长；Seedance／即梦单段保持4–30秒边界，工具适配不得改变最终执行阶段的镜长裁决、`timing-segmentation.md` 的视觉节点与长镜头规则或原文顺序。
