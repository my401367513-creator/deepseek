# 输出与格式模块

本模块是正式提示词结构、字段、省略规则和负向约束的唯一规则源。正式单集默认套用 `templates/director-compact.md`；工具差异由适配器覆盖字段，不得改写剧情规则。

## OUT-01 交付媒介与层级

- 默认在对话中输出可复制纯文本；需要保存时优先使用 `.txt`。
- 整集结构固定分为两个互不夹杂的区域：前区连续放置全部生成段可直接提交的视频模型提示词；后区依次放制作参考、原文映射、自动修复记录、长镜头报告（存在时）、执行与依据清单和交付检查报告。提示词区不得包含旁白、对应原文、创作理由、时长核算、诊断、状态或修改过程；以“复制后无需删除任何文字即可提交”为边界。
- Seedance／即梦使用可直接整体复制的连续词头，固定按 `【第<集数>集统一词头·严格锁定】 → 地域与类型及摄影风格 → 项目场景总体状态与美术限制 → 声音与文字边界 → 人物参考 → 道具参考 → 场景参考 → 初始空间状态` 排列；其他工具按导演指定的适配格式输出。
- 制作参考与可复制提示词明确隔离。旁白、对应原文和完整情绪分析只出现在制作参考；不得混入视频模型提示词。
- 推文项目的制作参考在集／EP标题后记录 `EP／场景范围`、`标黄旁白状态（使用／不使用）`、`旁白保留片段` 和 `对白替换位／角色对白单独生成`；这些字段只用于可追溯交接，不进入视频模型提示词。
- 两区使用固定醒目的纯文本标题 `══════════ 可直接提交的视频提示词 ══════════` 与 `══════════ 制作参考与审核 ══════════`。整集先列完全部生成段提示词，再进入后区；不得按单段交错排列制作参考与提示词。
- 故事画面阶段不预设平均镜长或统一单镜硬上限；正式视频提示词与剪辑执行阶段的最终镜长、普通镜头4秒上限、唯一高潮例外、全片硬切和由工具参数面板控制的画幅属于内部制作约束，不写入统一词头或逐镜描述。镜长判定统一服从 `timing-segmentation.md`；只有导演明确要求模型读取其中某项时才写入可复制提示词。

## OUT-02 词头与资产引用

- Seedance／即梦每个生成段的视频模型提示词以 `【第<集数>集统一词头·严格锁定】` 开头，完整保留统一词头的结构和固定顺序；其他工具按其已确认适配格式输出。所有工具都只填写当前生成段实际需要的人物、道具和场景，使任一生成段都能脱离其他段独立复制提交。
- 有对白固定人物使用 `<人物名称>：形象参考：@image<编号>，面部参考：@image<编号>，声音参考：@音频<编号>；`；无对白固定人物省略声音参考；无参考固定人物、临时人物与群演仍保留对应人物引用格式的模板占位符。
- 固定道具与无参考重复道具使用 `<道具名称>：道具参考：@image<编号>；`；固定场景、无参考重复场景与临时场景使用 `<场景名称>：场景参考：@image<编号>；`。未绑定参考保留模板占位符，但不虚构实际编号。
- 完成引用后不追加固定外观描写。Seedance词头末尾只写一段初始空间状态：人物初始位置、左右／前后／高低关系、朝向、距离、关系轴与摄影机所在侧，以及道具初始位置、朝向、持有人、持握／接触关系和当前状态。该段不得写动作流程、后续变化、人物知情／情绪解释或负向错误。
- 整集交付时不得用“同上”“沿用词头”或集中展示一次来替代逐段完整词头。
- 当前生成段不需要的资产及资产类别删除，不写空占位，也不因资产在其他生成段出现而带入。相同资产再次出现时，其名称和已绑定参考映射必须保持一致。

## OUT-03 每段自包含字段

- 每个生成段内部仍从0.0秒连续核算，并包含段号与总时长、自包含资产、初始空间状态以及逐镜时间范围卡。其他工具按导演确认的适配格式承载同等信息。制作参考镜头标题与可提交区保持同一累计时间范围格式。
- Seedance只在资产引用后保留一个初始空间状态段落，不另设“本段执行约束”。人物与道具的后续动作、视线、情绪证据、声音、越轴过程和状态变化只在实际发生的逐镜描述中书写；明确画面禁项只在相关镜头无法由正向状态排除时就地简短补充，不建立段级负向清单。

## OUT-04 镜头卡

- 每镜以 `【<起始秒数>-<结束秒数>】` 开头，起始与结束时间为本生成段内从0.0秒开始的累计时间，不显示“镜头一／镜头二”或“时长”字样；制作参考中的镜头标题使用同一时间范围，多镜共用原文时按时间范围标注。可提交区按“景别与主体 → 摄影机相对人物／场景的起始位置 → 机位高度 → 观察方向与角度 → 焦距和实际构图范围 → 可见初始状态、运镜触发、摄影机路径与沿途画面变化、人物连续动作及可见结束状态 → 同期或画外连续对白”顺序书写，不加入落幅、下一镜或下一段承接说明。固定机位省略不存在的运动过程；复杂运镜的起幅、过程和停止属于主体画面陈述，不得压缩成句末标签。
- 落幅、下一镜起幅和生成段末下一段承接统一写入制作参考区；按时间范围逐镜记录“落幅于……；下一镜从……承接”，生成段末镜记录“下一段从……承接”。承接必须有主体、动作、方向、构图或声音依据，不使用“自然承接”“顺势切换”等空泛表述。
- 景别字段只写实际景别和主体，不在“全景／中景／近景”等景别前添加“短暂闪回”“回忆”“梦境”或其他叙事标签；这类属性放入制作参考、场景状态或承接说明。
- 使用“能看到……”明确可视内容，并用“先、随后、接着、最后、与此同时”压缩重复主语、保持动作先后。不得为简写改变原有动作顺序、状态变化、口型归属或对白连续性。
- 镜头描述、初始空间状态、制作参考中的镜间落幅承接和生成段状态快照优先使用人物姓名或已建立的明确称谓，并在跨年龄、跨身份、回忆与现实并置时同时写明对应时期或状态。减少“两人、他们、他、她、对方”等代指；只有同一句内指向唯一、不会与其他人物或时期混淆时才可使用。群演资产名、团队名称和明确集合称谓不视为含混代指。
- 道具、声音、补充摄影约束、光影和连续性只有在当前镜头实际发生且无法由初始状态表达时，才在对应镜头段落末尾简短补充。项目要求省略某类描述时直接省略。已经参与画面陈述的运镜须写进动作与构图变化的先后过程，不在句末重复。整集或本段已经锁定的条件不逐镜重复，不保留空栏。
- 不设置“生成语言”“语言音轨”或单独“台词”字段。同期对白与画外连续对白原句只在人物表演中出现一次；音频行不重复台词。
- 每镜“对应原文”只显示在制作参考，不提交视频模型。
- 镜头描述不写摄影机或镜头厂商品牌；表演内部不写秒数、毫秒、持续时长或毫米级幅度。硬切作为内部制作规则执行，只有镜头存在特殊声音承接、动作阶段或段尾状态时才在该段末尾补充切点，不写泛化的“全部硬切”。

## OUT-05 分层负向

- 通用层只保留人物／肢体变形、身份漂移、闪烁、乱码、额外人物等高频画面错误。
- 针对层只写当前段明确禁止出现的画面错误，例如画外对白口型错配、人物位置互换、道具换手或消失、服装变化、光源漂移、镜面错误、重复脸或肢体粘连；负向约束不参与镜头选型，不得成为降低画面表现力的理由。
- 对剧情中确实存在、但不应清楚辨认的人物、物体或背景信息，不写“不可见”，统一改用可执行的虚化表达，并按画面选择浅景深失焦、前景虚焦、背景虚化或运动模糊，同时写明不得辨认的具体特征。原剧情明确不存在、导演禁止生成或会造成穿帮的元素仍写“不出现”，不得通过虚化把禁用元素引入画面。
- 先写清正向状态。不得用负向词禁止原剧情需要的雨、哭泣、拥抱、文字载体或动作，也不堆砌与本段无关的画质口号。

## OUT-06 项目沉淀

- 项目提示词、反馈、状态快照和结论只写入当前本地项目目录。通用规则只有经导演确认后才能更新技能。
- 后续局部更新保持现有资产名、编号、确认状态和已确认长镜头状态；未变化内容不重复询问。
