# AI短剧摄影机与镜头库

本库提供镜头用途与表现方法；剧情、时长、空间和硬切纪律服从规则模块。镜头选择以画面表现力为第一优先级，不进行生成稳定性评级，不因变脸、多人、遮挡、复杂运镜、物理交互或背景动态主动降级、简化或准备替代方案。

外部案例只用于提炼可迁移的画面构思、空间组织、注意力引导和镜头组合方法；调用时按当前原文和空间重新构思，不机械复刻。

## 景别与视角

| 镜头 | 主要用途 | 执行边界 |
|---|---|---|
| 大全景 ELS | 定场、地理关系、人物与环境比例 | 不承担精细口型 |
| 全景 WS | 全身动作、人物与场景位置 | 明确左右、前后和行动方向 |
| 中景 MS | 常规叙事，兼顾动作与表情 | 让关键动作和关系同时可读 |
| 中近景 MCU | 日常对白、轻微情绪变化 | 保留视线空间和对话对象方向 |
| 特写 CU | 关键台词、反应、信息落点 | 一镜突出一个核心变化或物件 |
| 大特写 ECU／微距 | 眼睛、嘴唇、指尖、关键道具 | 必须有剧情依据并确保动作入画 |
| 主观视角 POV | 角色所见、信息揭示、短时沉浸 | 写清视线来源和观察路径 |
| 半主观视角 | 贴近角色感受，同时保留第三人称空间判断 | 贴近视点人物的身高、位置和视线，保留身体边缘或运动痕迹 |
| 过肩 OTS | 对话关系、倾听反应、权力距离 | 锁定肩位、视线轴和口型归属 |

景别先服从叙事目的和必须看清的内容。动作、接触点或道具必须落在构图范围内，避免在人物关节附近生硬裁切。

## 高级景别与氛围方法

涉及景别跳级、景运耦合、视觉重量、3–5镜呼吸循环、场景化景别组织、时空匹配硬切、感情戏阶段、标志性技法族、景别禁忌、景光调度、空镜、前景和声画对位时，完整读取并执行 [shot-scale-atmosphere.md](shot-scale-atmosphere.md)。

涉及关系轴、运动轴、方向轴、180度法则、合法越轴、主动越轴、空间重建和越轴红线时，完整读取并执行 [axis-line.md](axis-line.md)。

## 机位、角度与构图

连续拍摄同一主体且景别相近、动作或信息变化不足时，可把约30度的机位差作为避免近似跳切的辅助摄影方法；它不构成合格通行证或否决条件。角度变化必须服从关系轴、运动轴、方向轴和视线匹配；即使超过30度而没有新信息仍可判为无效切镜，不足30度但存在清楚的动作阶段、观察对象、构图重心或认知变化也可成立。无法可靠确定精确角度时只描述可观察的机位侧别和构图变化，不虚构数字；完整判定服从 `modules/shot-continuity.md`。

| 方法 | 可服务的剧情动机 | 执行边界 |
|---|---|---|
| 平视 | 客观、平等、自然交流 | 关系未发生倾斜时使用 |
| 轻微低角度 | 权力上升、压迫或高光 | 保留真实空间高差和视线关系 |
| 极低仰拍／虫蚁视角 | 极端压迫、脚步冲击、规模强化 | 让前景尺度与目标位置形成明确层次 |
| 轻微高角度 | 脆弱、受困、空间劣势 | 不虚构不存在的制高点 |
| 垂直俯拍／顶视 | 阵列、路径、困局、地面动作 | 地面关系和动作方向清楚 |
| 荷兰角 | 明确的失衡、眩晕或失控 | 不作普通紧张装饰 |
| 三分构图 | 常规叙事、保留视线与行动空间 | 画面重心随人物行动变化 |
| 中心／对称 | 仪式、秩序、权威、刻板压迫 | 必须有空间对称基础 |
| 前景遮挡／窥视 | 纵深、监视、偷听、关系阻隔 | 遮挡有叙事作用，不覆盖关键信息；可作为匹配硬切点，不生成连续转场效果 |
| 框中框 | 束缚、隔离、观察关系 | 使用真实门窗、框架或镜面 |
| 引导线 | 空间方向和人物目标 | 线条真实存在并指向有效信息 |
| 留白 | 孤立、等待、空间压力 | 有对应旁白或延续对白承载 |
| 功能性空镜 | 环境、时间变化、事件结果、道具状态或人物离场结果 | 有对应旁白或画外连续对白承载，不作装饰或填时长 |
| 上下分屏 | 手机端明确要求的并行信息 | 仅由导演或项目启用，写清时间关系、主次和同步点 |

角度不是固定情绪公式。先核对真实位置、空间高差、视线关系和权力变化，再强化有依据的画面关系。

## 焦点与景深

| 技法 | 用途 | 执行边界 |
|---|---|---|
| 浅景深 | 对白特写、主体隔离、关键物件 | 明确焦点与背景信息取舍 |
| 大景深 | 空间关系、多层人物信息 | 写清前中后景和注意力顺序 |
| 焦点转移 | 前后景线索揭示、注意力转移 | 每次转焦改变信息归属 |
| 柔焦 | 有原文依据的回忆、梦境、柔和质感 | 不作普通美化，不损失人物识别 |
| 主观虚焦／失焦 | 昏厥、醉酒、视力异常或认知变化 | 明确感知主体，不承担必须看清的信息 |

## 运镜的画面陈述结构

先确定起幅交代什么、运动途中依次改变什么、落幅最终确认什么；沿途的前景、人物、道具和空间节点都应参与信息递进。

| 运镜 | 画面陈述方式 | 设计边界 |
|---|---|---|
| 固定机位 | 让表演、画内调度或动作结果成为变化主体 | 须有充分的画内变化与落点 |
| 推进 | 从环境或关系起幅，逐步排除次要信息，落幅锁定关键主体 | 推轨产生空间逼近；光学变焦只改变尺度 |
| 后撤 | 从面部、接触点或结果起幅，逐层纳入旁人、阻挡或环境 | 新进入画面的信息与原文有关 |
| 横摇／竖摇 | 从触发源起幅，沿视线、动作或空间关系落到结果 | 不作无目的扫景；落幅清楚后硬切 |
| 侧移 | 借视差改变遮挡和同框关系，揭示人物、出口、威胁或目标 | 方向和信息出现次序可读 |
| 跟拍 | 前跟读取状态，后跟共享目标，侧跟呈现动作与路径 | 主体、目标和运动方向持续可辨 |
| 环绕 | 通过背景更替、遮挡开合和相对位置变化重写关系 | 写清半径、方向、轴线变化和最终侧别；需要时可全环绕 |
| 升降 | 在宏观与微观之间转换，揭示等级、规模、包围或中心目标 | 写清真实路径、尺度变化与新增信息 |
| 俯冲 | 强化坠落、降临、竞速或尺度冲击 | 写清高度、目标、加速过程和落幅；可接贴地跟拍 |
| 甩镜 | 由声音、视线或动作触发快速转向并接住新主体 | 只作单镜内注意力转移，不遮盖切镜 |
| 缓慢光学变焦 | 不移动机位的注意力收紧 | 透视基本不变，不与推轨混写 |
| 急推／急拉 | 突发信息、喜剧或强反应点 | 一次完成并落在明确主体或结果上 |
| 希区柯克变焦 | 世界观崩塌、恐惧或震惊 | 主体位置、推轨方向、变焦方向和背景纵深清楚 |
| 定点变焦摇镜 | 混乱中搜索并锁定目标 | 写清搜索起点、方向、目标出现和锁定 |
| 低角度跟拍 | 角色高光、威压移动或脚步冲击 | 路径、前景尺度和人物目标共同建立气势 |
| 穿障跟拍 | 空间穿行、追逐、遮挡节奏和再揭示 | 每个遮挡节点有剧情意义，前后空间连续 |
| 极速环绕跟焦 | 动作高潮、失控或关系骤变 | 中心主体、方向、速度变化和落幅明确 |
| 降格／加速 | 时间压缩、重复劳动、忙乱或喜剧节奏 | 不承担需按自然时间读取的同期对白或逐步信息 |
| 快到慢／快慢快 | 动作峰值、撞击、落地或认知瞬间 | 速度变化对应明确动作阶段和情绪落点 |

复合运镜可采用一条主要空间轨迹加一次次级构图变化，也可按剧情组织多阶段连续路径。逐段写清触发、方向、速度、透视变化、新增信息和最终落幅；是否拆镜只由叙事、动作可完成性、信息可读性和剪辑表现决定，不由生成稳定性决定。

## 对白叙事与回忆插镜

| 方案 | 适用信息 | 执行边界 |
|---|---|---|
| 说话者当前表演 | 态度、请求、承认、当下关系 | 保留自然口型与话后落点 |
| 道具承载的画外连续对白 | 对白核心落在已有物件、持握或交接 | 道具状态跨镜一致，画外说话者声音连续 |
| 有原文依据的回忆插镜 | 对白明确叙述过去的动作或结果 | 只拍原文信息，不新增设定 |
| 画外来源进入、主体接取 | 抛入、递入、声音或物件从画外到达 | 写清方向、轨迹、准备、接触和收势 |

- 回忆镜头标题只写实际景别；回忆属性由制作参考、场景状态和承接表达。
- 原文重点是物件到达而非提供者身份时，可让物件从画外进入；不得删除原文明确要求出镜的人物。
