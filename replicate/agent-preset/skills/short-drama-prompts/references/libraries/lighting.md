# AI短剧光影与色彩库

本库用于建立物理光源、选择光型并核对跨镜连续性；项目风格边界服从规则模块。光影以画面表现力和剧情作用为先，不做生成稳定性评级，也不因动态、多色、低照度、逆光或复杂换光主动降级。

## 场景光影锁定字段

```text
时段与天气：<室内/室外，具体时段，天气>
实景光源：<窗、太阳、顶灯、台灯、路灯、屏幕等及其位置>
主光：<来源、画面方向、人物受光侧、硬/软、色温>
辅光：<来源、方向、强弱或与主光的反差关系>
轮廓/背景光：<有则写真实来源；无则写无>
阴影：<方向、边缘软硬、密度>
曝光：<正常、高调、低调；高光与暗部保留要求>
基础色彩：<主色、中性色、点缀色、肤色要求>
连续性锁定：<不可随镜改变的光源、方向、色温与影子>
允许变化：<剧情触发条件及变化后的状态>
```

## 光型、实景光与色彩

| 方案 | 真实来源与用途 | 执行边界 |
|---|---|---|
| 自然日光／阴天漫射光 | 窗外天空、太阳或云层 | 写清方向、时段和阴影状态 |
| 金色时刻／蓝调时刻 | 晨昏太阳、冷天光与室内灯 | 时段成立并继承室内外关系 |
| 高调柔光／低调高反差 | 窗光、柔化灯、白墙反射或窄束实景灯 | 保留剧情要求读取的面部、动作和道具 |
| 伦勃朗式侧光／顶光／底光 | 侧上方窗灯、吊灯路灯、火焰或屏幕 | 必须有对应真实光源 |
| 逆光／剪影／轮廓光 | 背后窗、灯或太阳 | 剪影不承担必须看清的口型、表情或身份信息 |
| 体积光 | 雾、尘、水汽与窄束光源 | 同时写明介质和光源 |
| 门缝／窗缝光 | 揭示、窥视、空间阻隔 | 形状服从真实开口，位置连续 |
| 屏幕光／路灯与车灯 | 手机、电脑、电视、道路灯具与车辆 | 明确作用范围、方向、速度和路径 |
| 冷外暖内／暖外冷内 | 室内外真实色温对比 | 固定空间关系，不逐镜翻转 |
| 霓虹混合光 | 店招、街区霓虹 | 颜色、闪动和扫过路径有场景依据 |
| 烛火／火焰 | 可见火焰 | 波动与火焰大小、距离和遮挡同步 |
| 灯光闪烁／快速换光 | 故障、警报、演出、车辆或能量变化 | 写清触发、频率、颜色、作用区域和结果 |
| 中性、暖色或冷色主导 | 由真实光源与材质形成 | 保留肤色及关键资产识别色 |
| 青橙分离／低饱和／高饱和点色／单色倾向 | 有剧情或场景依据的色彩组织 | 明确主次、边界和视觉落点，不作无依据滤镜 |

## 光线变化协议

连续场景只在时间、天气、开关灯、拉帘、开门、人物进入另一光区、移动实景光源、闪烁、警报、火焰或能量状态变化时改变。写明触发、变化路径、作用区域、新旧色温与方向、人物和道具的可见受光结果，以及下一镜继承状态；没有触发则保持不变。

## 常见画面错误与修正

- 光源漂移：复述固定方位和人物受光侧。
- 无源轮廓光：增加合理光源或删除轮廓光。
- 肤色跳变：锁定肤色与白平衡，只改变有依据的受光状态。
- 影子跳轴：锁定主光方向和人物、摄影机的真实位置关系。
- 强光吞掉剧情信息：重组曝光或构图，让必要信息可读。
- 动态光缺少因果：补充光源、触发、路径和落幅状态。
