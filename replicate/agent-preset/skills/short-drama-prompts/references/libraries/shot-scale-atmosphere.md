# 景别切换与氛围高级方法库

本库完整保存导演确认的景别、场景调度、氛围和声画组织方法。它负责提供创作方法，不改变原文、音频、时长、资产、硬切和输出规则。

## 执行解释

- 景别层级按“大远景／大全景 → 远景／全景 → 中景 → 中近景／近景 → 特写 → 大特写／微距”理解；同一层内部调整不算跳级。
- 文中的固定级数、3–5镜循环、1–2帧强调和1–2秒节奏是创作目标和检查标尺，不在故事画面阶段预先锁定秒数。正式视频提示词与剪辑执行仍须让语言、动作和信息自然完成，并服从时长模块的最终执行阶段镜长、普通镜头4秒上限和唯一高潮例外；没有逐帧控制时把1–2帧转译为短促但可辨认的特写落点。
- 文中的“无缝转场、穿档切、景别转场、匹配转场”统一执行为直接硬切：前镜内部完成遮挡、缩放、运动或构图匹配，落幅明确；下一镜从对应锚点起幅，不使用淡入淡出、叠化、溶解、变形或生成式连续转场。
- 空镜、物件镜头和无人物画面仍须由对应旁白、同期对白或画外连续对白承载，并提供新信息、状态变化或情绪结果；不得只靠环境音存在。
- 光影技法只能使用项目已经建立的真实光源，变化必须有时间、天气、开关灯、人物移动或环境变化等可见依据。声音层次只使用对白、呼吸、拟音和剧情必需声源，不自动添加泛化环境音、心跳或背景音乐。
- 所有技法先服从原文事实、人物知情状态、空间几何、轴线、逐镜落幅承接与每段资产边界；同一场戏不必把所有技法同时用完。

## 一、通用顶层法则

### 1. 景别跳级与情绪量级

- 跨1级，例如中景到特写，用于情绪小幅升级、注意力明显集中或一个关键反应落定。
- 跨2级，例如全景到特写，用于强戏剧冲击、权力骤变、真相揭露或认知翻转。
- 跨3级，例如大远景到大特写，保留给单集或全片最强高潮；必须先保证空间与主体可以被观众识别。
- 反向从特写跳到全景或大远景，用于荒诞、疏离、关系割裂、人物被环境吞没或视点抽离。
- 跳级跨度必须对应情绪、信息与关系变化强度；无目的跨级属于禁忌。

### 2. 景运耦合

- 景别收紧时优先考虑摄影机前推、人物靠近或构图压缩；景别拉开时优先考虑后撤、人物离开前景或重新纳入环境。
- 运镜速度与情绪、语速和景别变化速度同向组织。快速跳切前，前镜运动在清楚落点骤停或收束，以动静反差强化冲击；不能在动作含混处强停。
- 景别与运镜不是机械绑定；固定机位、人物调度或硬切更能表达原文时可以不用推拉。

### 3. 视觉重量平衡

- 前后镜头即使景别不同，也检查主体占比、明暗分布、色彩密度和构图重心，使普通承接保持视觉重量平衡。
- 压迫、失衡、疏离、荒诞或信息反转需要不平衡时，必须把不平衡作为有动机的关系变化，并由下一镜接住，不能成为无意的构图突变。

### 4. 景别呼吸循环

- 场景长度允许时，每3–5个镜头规划一次“收缩—舒张”呼吸：全景／中景建立关系，近景／特写收紧到情绪或信息落点，再适度回到近景／中景／全景释放压力。
- 情绪持续压迫、突然爆发或刻意屏息时允许延迟、打断或冻结循环；不得为了完成循环新增镜头或改写原文。

### 5. 氛围底层逻辑

- 景别控制心理距离，光影定义项目允许的情绪基调，构图强化关系张力；三者必须服务同一叙事重点。
- 光影和色彩不随景别无依据变化；构图也不能为了氛围破坏人物位置、口型、道具和空间连续。

## 二、全场景高级景别切换

### A. 双人对话与对峙

基础逻辑：外反打中前景肩膀占比越大，压迫和阻隔越强；内反打更贴近视点人物，情绪浓度更高。关系对等时双方初始景别相近，权力变化后景别、主体占比和运动状态随关系改变。

1. **同步递进正反打**：用于告白、谈判升级和真相揭露。双方景别同步逐步收紧，摄影机可随语速和情绪慢推；顶点以短促、可辨认的手指、喉结、呼吸或视线特写落点强调。
2. **单边压迫正反打**：用于训话、审讯和权力碾压。强势方持续收紧并前推，弱势方保持或逐步拉开；一动一静必须对应已发生的权力变化。
3. **错位疏离正反打**：用于冷战、分手和涉密对话。双方不完全正面对接，景别一近一中，配合缓慢横移或留白表现隔阂；仍须保持真实轴线和沟通方向。
4. **纯特写正反打**：用于生死告白和终极对峙。暂时压低环境信息，用脸部或眼部特写集中微表情；每次反打必须出现新的态度、认知或动作阶段。
5. **无剪辑正反打**：用于生活化对话和沉浸式对峙。以单镜横移、侧移、半环绕或焦点转移交接双方，经过人物时自然形成过肩或近景；故事画面阶段先服从对话节奏和关系变化，正式视频提示词与剪辑执行阶段再服从普通镜头4秒上限；只有本集唯一高潮镜头可按时长模块例外处理。

氛围方法：权力对峙可用项目已有硬侧光强化面部切割；暧昧对话可用已有柔光弱化边界；悬疑对话可使用真实光源形成明暗分区，让信息在阴影与可见区域间逐步揭示。

### B. 多人群像对话

核心为三层嵌套：全景层建立空间和站位；中景分组层区分核心对话区与旁观区；近景／特写个体层聚焦说话者、执行者或关键反应者。空间已建立时可从当前层继续，不重复定场。

- 环形运镜景别流：摄影机围绕群体缓慢环移，经过核心人物时收紧，经过边缘层时拉开；沿途每次层级改变必须新增信息。
- 焦点转移式切换：同一固定构图通过焦平面前后移动改变注意力和信息归属，无需额外剪辑。
- 群体正反打：围绕核心说话者选择真正改变责任、判断或关系的反应；话语权越高可采用越近景别，但不能按座次逐人轮流。
- 群像对峙可用已有顶光形成分隔；温馨群像可用项目确认的暖调平光保持整体感。灯光必须服从真实来源与连续性。

### C. 动作、追逐与格斗

核心为空间锚点动作链：远景／全景交代格局和敌我位置，中景显示完整肢体动作，特写强化打击点、受力和关键道具。

- 动作穿档硬切：人物或物体完全经过前景时，前镜明确落在遮挡或动作阶段，下一镜以同方向、同阶段或紧接阶段直接硬切起幅；不生成连续遮挡转场效果。
- 景别加速度：动作高潮加大景别跳级幅度和切换频率，用景差强化冲击，但必须保持空间与动作可读。
- 运动匹配硬切：前后镜运动方向、受力方向和动作阶段一致，切换不让动作复位。
- 跟拍长镜头景别调度：通过摄影机前后移动、侧跟或环绕，在连续动作中改变景别，用调度替代多余剪辑；路径、目标和落幅必须清楚。
- 痛感特写可拍肌肉受力、指节收紧、接触点和身体反馈；视线特写预判攻击方向；道具特写确认动作目的与结果。
- 硬核动作可使用项目既有高反差硬光，追逐可使用有依据的轻微手持和环境运动虚化，雨夜动作可利用真实积水反光与持续雨态；不能为风格凭空改变天气或光源。

### D. 心理独角戏

核心为呼吸式进退：中景建立处境，近景聚焦，特写确认触发或生理证据，再回到近景／中景表现抽离、稳定或结果。

- 景别割裂：理智阶段使用稳定中近景；崩溃阶段可插入不规则但有切镜资格的特写，以节奏割裂表现心理混乱。
- 空镜景别过渡：人物特写可硬切至有原文承载的雨滴、时钟或既有物件特写，再硬切至更大景别中的人物；空镜必须改变时间、状态或认知。
- 极致特写可使用瞳孔、睫毛、颈部脉动、指尖等生理证据；没有逐帧控制时保证细节在镜长内可辨认，不虚构摄影机拍不到的动作。
- 孤独可使用大面积留白与项目已有冷光；崩溃可使用有空间依据的倾斜构图和手持；释然可使用慢推与既有柔光。选择必须符合原文和项目光源。

### E. 悬疑、惊悚与恐怖

先选择信息差：观众全知型用全景展示危险、近景展示人物尚未发现；观众未知型只给人物反应，不提前展示危险本体；人物全知型保留人物掌握的信息，让观众通过表演和有限线索推断。

- 延迟景别揭示：线索特写 → 人物反应近景 → 缓慢拉远揭示全貌。
- 二次跳切惊吓：先切稍远景别释放部分压力，再以有明确新威胁的极速大特写形成第二次冲击；不能重复同一惊吓信息。
- 窥视景别收缩：从远景或受限视角逐步推近至特写，持续缩小安全距离。
- 不对等正反打：反派可用全景、背影、虚焦或局部特写保持信息不完整；主角用近景和大特写放大已知情绪。不得泄露原文尚未揭示的身份。
- 日常场景可用反常低角度制造违和；黑暗环境可用真实局部束光限制可视范围；门框、帘幕等前景可建立窥视感，但不遮挡必须读取的信息。

### F. 史诗大场面

采用宏观—中观—微观三级嵌套：大远景／远景建立地貌和规模；全景／中景展现群体行动和事件进程；近景／特写落到个体命运与情绪。

- 上帝俯冲式景别转换：从高空大远景俯冲，沿真实路径穿过云层、建筑或人群，最终落到单个人物近景／特写；每一级新增尺度或事件信息。
- 平行蒙太奇景别同步：多条叙事线随高潮同步收紧，在共同事件点汇聚到同量级特写；各线仍按自身动作落点硬切。
- 战争史诗可使用项目确认的冷灰调、烟尘与真实逆光；科幻史诗可用低饱和大色面和轮廓光；群像牺牲可用逆光剪影和经审批的慢镜头。不得覆盖项目风格或补造环境状态。

### G. 时空转场

1. **景别量级匹配硬切**：以前后镜相同量级景别、同构图重心或同类主体完成硬切，保持注意力位置连续。
2. **两级反差硬切**：从门把手、笔尖等极小景别直接硬切到建筑、城市或星球等极大景别，表达明确的大跨度时间或空间变化。
3. **递归式景别硬切**：前镜特写包含下一场景已有元素或形状，前镜在该元素上落幅，下一镜以对应构图的场景全景起幅；不使用变形、放大穿越或连续生成转场。

回忆可在项目允许时使用柔光、暖调或轻微柔焦，平行时空可使用同构图与不同光影显示关联；差异必须由项目状态和真实光源支持。

### H. 感情戏

核心：景别远近表现心理距离，运镜轨迹表现靠近、迟疑或抽离，正反打对称度表现关系是否对等；必须与视线、姿态、距离和表演证据一致。

1. **暧昧试探**：以中景、中近景保留社交距离，关键对视、指尖或接触才短时特写；错位正反打可一近一中并保留留白。极缓环绕、进退或轻微焦点漂移表现拉扯；真实门框、窗帘或人群可作前景。灯火、水面、树叶等空镜只有在原文与音频承载时使用。
2. **深情告白**：由中景逐步推进至近景、脸部或眼部特写；视线从回避转为直视，景别由不对等走向对等。运镜采用极缓匀速慢推，顶点可保留可控的呼吸感；喉结、指尖接触或瞳孔等特写必须可见。环境声音只在有依据时弱化到对白与呼吸焦点。
3. **亲密热恋**：多用双人近景和双人特写，让共享构图与相互视线弱化空间边界；可用交叉构图和轻微生活化跟拍。镜头节奏可相对松弛，正式视频提示词与剪辑执行阶段仍核对普通镜头4秒上限；发丝、影子、蜡烛等意象只有原场景真实存在且有音频承载时使用。
4. **争吵冲突**：由双人中景分裂为单人近景或特写，随冲突升级加快有效切换；愤怒占优方可更近，受伤弱势方可更远，高潮双方均可进入特写。正反打频率可随自然语速和意义转折加快；轻微手持与顶点骤停必须有动作落幅。逼仄空间和硬光只在项目真实存在时使用。
5. **决裂分手**：从特写拉远到中景、全景或大远景，人物占比逐步缩小；视线错开、取消同框、人物离画和空位结果表现关系割裂。可用固定机位让人物离画，或缓慢后撤；最后触碰、泪光、转身和关门只选原文已有动作。雨、空房、烟蒂等空镜不得凭空新增。
6. **思念缅怀**：以单人中景、近景和留白表现缺失；有依据的回忆可使用较柔特写，与现实形成质感差异。缓慢横移、轻推或固定长镜头表现追寻与凝固；旧信物、街角、咖啡等物件只在原文或资产中存在时使用。回忆对白可作为画外连续对白覆盖现实画面，但不得与旁白重叠。

## 三、标志性技法族

- **希区柯克式变焦推拉**：摄影机前推同时反向变焦，尽量保持主体景别稳定，让背景透视扭曲；用于眩晕、不安或世界崩塌，并写清推轨、变焦方向和背景纵深。
- **库布里克式对称固定与极慢切换**：使用有真实空间基础的对称构图、固定机位和克制切换制造审视、冰冷或宿命感；不得把对称强加给非对称场景。
- **王家卫式碎片化景别跳切**：近景／特写碎片与慢镜头中景并置，用于时间朦胧或情绪破碎；每个碎片仍须有原文承载、新信息和硬切承接。
- **罗杰·迪金斯式光影匹配**：以前后镜真实光向、明暗分布和色温关系作为硬切匹配依据，使观众注意力随光影延续；不得无触发改灯。
- **是枝裕和式生活流留白**：固定中景、全景、平缓切换和生活化表演承载细腻情绪；留白和空镜仍须有旁白、对白或剧情结果。
- 调用以上名称只表示技法族，不复制特定作品、镜头或完整个人风格；最终方案按当前项目重构。

## 四、景别禁忌

1. 禁止无情绪、信息或关系依据的跨级跳切。
2. 禁止无权力或关系变化支撑的正反打景别失衡。
3. 禁止新空间尚未建立便直接用特写使方位丢失；原文有意隐藏空间时须明确采用受限信息策略。
4. 禁止景别节奏与情绪错位，例如舒缓段落无意义频繁特写、紧张事件长期停留在无法看清动作的全景。
5. 禁止特写滥用；特写必须保留景别对比和明确的信息落点。
6. 禁止氛围与景别脱节；光影、色彩和构图不能与当前关系和项目光源逻辑矛盾。

## 五、氛围感进阶技法

1. **景光一体调度**：推镜收紧时，可让人物从环境光区进入既有主光区；拉镜展开时，可逐步纳入已有环境光。光线变化必须来自摄影机路径、人物位置或真实光源覆盖，不生成无触发调光。
2. **空镜情绪锚点**：大景别空镜定调，特写空镜承载物件或环境结果；只在情绪转折确有旁白或画外连续对白时使用，并让景物提供新状态，不把空镜当通用转场。
3. **呼吸感剪辑**：故事画面阶段先按情绪和视觉节点组织舒展或急促，正式视频提示词与剪辑执行阶段再以普通镜头4秒上限、唯一高潮镜头5–6秒上限和全片2.5–3.5秒平均值核算，并按音频、表演、动作和工具边界锁定。
4. **前景层次**：优先为各景别寻找真实、具有关系意义的前景，如门框、珠帘、人群或雾气；特写可保留轻微虚化前景。不存在有效前景或会遮挡口型、动作、道具时省略。
5. **声画景别对位**：全景优先明确空间性剧情声源，中景突出清晰对白与动作，特写突出呼吸、吞咽、布料或接触细节；只保留当前剧情必需声音，不自动增加环境底声、心跳或音乐。
