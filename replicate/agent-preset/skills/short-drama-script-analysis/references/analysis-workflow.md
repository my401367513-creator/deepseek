# 剧本分析工作流

本文件是整剧模型、逐场拆解、三类人类报告、问题分级和受约束推定的唯一规则源。分析解释剧本如何运作并为下游建立事实工具；它不评价项目是否值得制作，不以修改清单为主轴，也不改写原剧情。

## 证据等级

重要结论绑定原文位置，并标为`原文明示`、`前后文可唯一推出`、`导演确认`、`临时工作假设`或`分析判断`。前三类可作为正式剧情事实；导演确认必须保留导演原话或可定位确认记录及其作用域，后两类不得冒充事实或导演确认。

## 整剧与逐场模型

有完整剧本时先建立整剧模型，再下钻到集、原场号和戏剧节拍；只有局部资料时标明范围与不可推出的结论。整剧模型覆盖核心命题与类型承诺、主线因果链、人物目标／秘密／知情状态、关系与权力变化、时间与空间迁移、关键道具状态、信息揭示顺序、情绪强度曲线、每集职责与集末推动力，以及未闭合伏笔、承诺和剧情债务。

保留原场号，在场内按目标、阻力、信息、关系或情绪的实质变化划分戏剧节拍。为导演执行手册和下游视觉判断同步记录“事件触发 → 冲突显形 → 反应波动 → 空间张力”的可证明链条，并为关键细节标注事实／关系／情绪／线索／后果功能；无法证明的链条保持未确认，不用抽象气氛补齐。每场记录原文范围与职责、入场状态、人物目标、阻力与冲突、戏剧节拍、信息持有与转移、行动—反应因果链、情绪链、关系／权力变化、空间与道具、不可逆结果、下一场触发、整集／整剧职责、可视化／可表演／可制作程度、证据、问题状态和临时工作假设。空栏目写“不适用”，不补造事实；逐场结论回写整剧链条。

## 原剧情保护

允许指出因果表达不清、人物动机缺少现有铺垫、动作／情绪／场景衔接不足，并给出只使用现有事实的最小呈现方向。允许方向仅限可见动作、反应、空间变化、信息来源显化和已有线索强化；不得调整场次顺序、删减支线、新增冲突、修改人物决定／关系结果／反转／结局或改写台词。分析方向不是实施授权。

## 表达与连续性账本

问题分为`阻断`（下游无法安全依赖）、`严重`（关键链未成立）、`一般`（剧情可理解但表达链不完整）和`优化`（纯呈现增强）。每条记录位置、原文证据、证据等级、问题类型、等级、断裂链条、影响范围、允许的最小方向、禁止触碰的剧情事实、责任技能和状态。状态只使用`仅诊断，禁止实施`、`待导演确认`、`导演已确认，可实施`、`已由下游处理，待复核`、`已复核关闭`；缺少状态时按禁止实施处理。

## 受约束推定

遇到阻断时不中止整份分析；从同一剧本前后文、已确认人物动机／能力／知情状态及时间、空间、道具和关系状态中选择最短连接，建立可撤销的`临时工作假设`。类型惯例或现实常识只能弱排序；其他项目、新人物、新事件、新道具和隐藏设定不得作为解释来源。

多个解释按：保持明确事实 → 不新增剧情元素 → 与最多证据一致 → 最小改变动机与知情状态 → 最小影响时间／空间／道具 → 最低返工传播 → 假设最少且最易撤销。商业表现、刺激度和制作便利不参与排序。

推定账本记录触发问题、证据、排除方案、影响文件、失效条件及撤销后重跑范围。它只解除分析和规划阻断；下游可据此做候选稿，不得升级为当前有效交付。新证据冲突时立即撤销，并沿因果、信息、情绪、关系、时间、道具和下游依赖图重跑受影响分支。

## 临时假设升级

导演确认某项临时工作假设时，先核对确认对象、准确表述、适用集／场／阶段及是否授权下游实施；含糊确认继续保持临时状态。确认充分时保留原假设ID并标记`superseded`，记录导演确认原话或消息定位、日期、作用域和受影响ID，再新建稳定事实ID，证据等级标为`导演确认`并用`promoted_from_assumption_id`关联原假设。随后更新交接索引的`fact_ids`／`confirmed_action_ids`、受影响报告和问题状态，重跑影响分支及全部分析审核门；审核通过后才能更新 `00-当前状态.md` 的当前分析指针。导演撤回或缩小确认时按关联ID撤销／限缩新事实，并重跑同一影响范围。

## 人类报告

- `编剧室逐场拆解.txt`：整剧—逐集—逐场—节拍分析，附表达与连续性账本和推定账本。
- `制片执行评估.txt`：人物／群演／场景／道具规模，时空、天气、服化、特效、动作复杂度，连续性风险、资产复用、依赖、阻断、返工传播、制作顺序和前置准备；资料不足时只给相对成本与排期等级，不要求改剧情。
- `导演执行手册.txt`：每场事件触发、冲突显形、反应波动、空间张力、观众注意力任务、关系与调度目标、表演节拍、情绪阶段、空间建立、道具因果、细节功能、动作重点、视觉母题、场景基调、声音重点、必须拍清的信息和防泄露边界；不预先锁定逐镜、焦距或运镜。

三份报告共享同一事实模型且职责隔离；事实冲突即审核失败。

## 影响更新

原文或导演结论变化时，沿依赖图计算真实影响范围，定点更新相关场景、全局链条、报告和交接索引，并复核未受影响结论。不得只改局部而忽略传播，也不无差别重写全部报告。
