# 输出与格式模块

本模块是正式提示词结构、字段、省略规则和负向约束的唯一规则源。正式单集默认套用 `templates/director-compact.md`；工具差异由适配器覆盖字段，不得改写剧情规则。

## OUT-01 交付媒介与层级

- 默认在对话中输出可复制纯文本；需要保存时优先使用 `.txt`。
- 整集结构固定为：各生成段制作参考 → 每段完整统一词头与该段视频模型提示词 → 长镜头报告（存在时）→ 交付检查报告。
- 统一词头必须是一个可直接整体复制的连续区块，将镜头风格、声音边界以及本集场景、人物、道具引用合并在同一标题下；不得再拆成“镜头风格”“场景资产”“人物资产”“道具资产”等多个并列锁定区块。
- 制作参考与可复制提示词明确隔离。旁白、对应原文和完整情绪分析只出现在制作参考；不得混入视频模型提示词。
- 默认4秒镜长上限、全片硬切和由工具参数面板控制的画幅属于内部制作约束，不写入统一词头或逐镜描述；仍须实际执行，并在交付检查中核对。只有导演明确要求模型读取其中某项时才写入可复制提示词。

## OUT-02 统一词头与集中资产

- 完整镜头风格、声音边界以及人物、场景和道具资产清单合并为一个 `【第<X>集统一词头·严格锁定】` 连续区块，并在每个生成段的视频模型提示词开头原样完整重复，使任一生成段都能脱离其他段独立复制提交。固定人物统一写为 `<人物名称>：形象参考：@imageN，面部参考：@imageN，声音参考：@音频N；`；固定场景统一写为 `<场景名称>：场景参考：@imageN；`；固定道具统一写为 `<道具名称>：道具参考：@imageN；`。引用后均不追加固定外观描写；人物声音不再另设独立清单。
- 词头内部可用空行区分风格句、场景行、人物行和道具行，但单个生成段内不得增加第二个锁定标题，也不得拆选或改写词头内容。整集交付时不得用“同上”“沿用词头”或集中展示一次来替代逐段完整词头。
- 每个生成段只引用本段实际使用的资产名，补充当前位置、姿态、动作、视线、受光、持握、交接、起止和连续性等动态状态；不得复制整集清单或固定外观描述。
- 本段无人出镜且没有人物画外连续对白时，省略“人物”整行；存在画外连续对白时保留说话者资产名、离画状态和声音承接。
- 本段没有实际使用道具时，省略“道具”整行。一次性临时人物、场景或道具可在实际出现的段落直接写必要文字。
- 人物、道具和针对性负向的同类省略自动执行，不再逐段询问导演。

## OUT-03 每段自包含字段

- 每个生成段从0.0秒计时，并包含：段号与总时长、本段动态资产状态、空间与承接、简短通用负向、逐镜时间卡，以及音频模块规定的“无背景音乐；不生成旁白”。
- “空间与承接”写左右、前后、高低、面向、距离、视线轴、摄影机状态和上一段结束快照；首段写初始状态。
- 每段必须保留简短通用负向。只有通用层未覆盖的真实风险才增加“本段针对性负向”；没有额外风险时省略整个标题和内容，不写“无”或空占位。

## OUT-04 镜头卡

- 每镜以醒目时间范围开头，并默认只使用一个连续段落。按“景别与主体 → 摄影机相对人物／场景的位置 → 机位高度 → 观察方向与角度 → 焦距和实际构图范围 → ‘能看到’的初始状态、触发、连续动作与结束状态 → 同期或画外连续对白”顺序书写。
- 景别字段只写实际景别和主体，不在“全景／中景／近景”等景别前添加“短暂闪回”“回忆”“梦境”或其他叙事标签；这类属性放入制作参考、场景状态或承接说明。
- 使用“能看到……”明确可视内容，并用“先、随后、接着、最后、与此同时”压缩重复主语、保持动作先后。不得为简写改变原有动作顺序、状态变化、口型归属或对白连续性。
- 道具、声音、运镜、光影和连续性只有在当前镜头存在特异性执行要求时，才在同一段落末尾简短补充；项目要求省略某类描述时直接省略。整集或本段已经锁定的条件不逐镜重复，不保留空栏。
- 不设置“生成语言”“语言音轨”或单独“台词”字段。同期对白与画外连续对白原句只在人物表演中出现一次；音频行不重复台词。
- 每镜“对应原文”只显示在制作参考，不提交视频模型。
- 镜头描述不写摄影机或镜头厂商品牌；表演内部不写秒数、毫秒、持续时长或毫米级幅度。硬切作为内部制作规则执行，只有镜头存在特殊声音承接、动作阶段或段尾状态时才在该段末尾补充切点，不写泛化的“全部硬切”。

## OUT-05 分层负向

- 通用层只保留人物／肢体变形、身份漂移、闪烁、乱码、额外人物等高频风险。
- 针对层只写当前段真实风险，例如画外对白口型错配、人物位置互换、道具换手或消失、服装变化、光源漂移、镜面错误、重复脸或肢体粘连。
- 先写清正向状态。不得用负向词禁止原剧情需要的雨、哭泣、拥抱、文字载体或动作，也不堆砌与本段无关的画质口号。

## OUT-06 项目沉淀

- 项目提示词、反馈、状态快照和结论只写入当前本地项目目录。通用规则只有经导演确认后才能更新技能。
- 后续局部更新保持现有资产名、编号、确认状态和已确认长镜头状态；未变化内容不重复询问。
