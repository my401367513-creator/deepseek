# 身份与参考权威

本文件拥有人物身份参考等级、职责冲突、角度与相似度判断规则。

## 权威等级

同一职责内按以下顺序处理；导演明确确认的特殊优先级可以覆盖默认顺序：

1. 原始身份权威参考。
2. 导演确认的标准人物资产。
3. 当前时期或造型参考。
4. 当前编辑目标。
5. 构图或风格参考。
6. 未确认生成结果。

- 低等级输入不得覆盖高等级身份、时期或造型事实。编辑目标不自动取得身份权威，构图／风格参考不自动取得人物、服装或场景事实权威。
- 已漂移成图不得成为下一轮唯一身份依据；编辑时同时提供更高等级参考，并明确保持身份特征、编辑目标内容和允许变化范围。
- 新生成结果只有经导演确认并登记后才能升级为资产参考。

## 身份可辨性

- 身份敏感任务优先选择能比较双眼、鼻、嘴、下颌和发际的正脸或三分之二正脸；只有侧脸参考充分时才要求极端侧脸。
- 强烈表情、广角近摄、重度逆光、遮挡和高度风格化会降低身份可辨性。首次设计不因风险自动降级，但必须判断当前任务是否仍能验收身份。
- 修复身份时描述可观察差异，如脸型、眼距、鼻长、唇形、下颌、发际和发型；不得只写“更像一点”。

## 多参考职责

- 一张输入承担多个职责时逐项声明，例如“身份＋当前服装”；没有声明的背景、姿势、表情和构图不自动锁定。
- 多张参考冲突时，按职责分别裁决；不得让造型图覆盖身份图，也不得让构图图覆盖当前剧情服装。
- 参考映射、文字描述和当前剧情冲突时，先记录冲突并按项目确认顺序解决，不静默混合。
