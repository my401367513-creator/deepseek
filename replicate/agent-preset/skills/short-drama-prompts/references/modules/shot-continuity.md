# 镜头、空间与连续性模块

本模块是镜头执行、空间几何、动作连续、段间快照和硬切的唯一规则源。镜头选型按需查 `libraries/camera.md`；关系轴、运动轴、方向轴和越轴方法读取 `libraries/axis-line.md`；镜长与分段由 `timing-segmentation.md` 管理。

## CAM-00 先构思画面关系

- 多人走位、复杂出入口、重要道具方位或容易混淆的空间关系，先用能够清楚建立人物位置、朝向、距离和行动路径的空间基准镜头；它可采用全景、双人中景或侧写中景，不固定为大全景。空间已由前文或前一生成段清楚建立时不得重复定场，后续近景、过肩和动作镜头须继承其轴线与位置关系。
- 列镜头前先把当前叙事单元转换为一条可见关系链，明确人物控制权、距离、接触关系、注意力和信息归属如何从开始状态变化到结束状态；随后才选择景别和机位，不以正反打模板代替画面构思。
- 优先用原文已有的人物调度把关系视觉化：靠近或退开、进入或离开构图、保护或松手、接触或挣脱、遮挡或让出视线通道。动作必须符合剧情和人物知情状态，不得为了“电影感”补造关系变化。
- 已有道具若能参与剧情，先建立“出现／持有 → 使用或影响人物 → 可见结果 → 后续状态”的因果链；道具特写只有在揭示刺激来源、关键线索、动作结果或关系变化时成立，不作装饰性插镜。
- 设计观众注意力路线，让前镜的动作、视线、声音、道具或构图重心自然引出下一主体。反应镜头除表情外还应承担默认、拒绝、判断、认知、关系转移或下一动作触发中的至少一项，不拍没有新增意义的反应。
- 对白的情绪递进可与空间变化配合：接近、压缩距离、越过边界可强化有原文依据的压迫或亲密；后退、转身、松手或让位可表现抽离、权力转移或暴露新的关系对象。空间动作不机械绑定固定情绪。
- 群像和背景人物按剧情分层。需要突出核心冲突时，背景可继续既有活动或保持克制，以建立环境态度和空间层次；不得让所有人同步反应、抢占主体，也不得凭空赋予群像新的剧情立场。
- 制度空间中的背景活动按主运动、次级运动、弱运动和静态层组织；主事件发生后的反应沿距离、视线、职责或指挥关系传播，不让所有人机械同步。进入主角情感核心后，背景退到景深、遮挡边缘或远景；只有动作直接影响主角安全、选择或因果时才重新进入清晰构图。
- 摄影机的揭示路径可参与人物塑造：从有剧情意义的持物、姿态或局部状态移动到面部时，沿途信息须形成“外部符号／动作状态 → 人物态度”的阅读顺序；不得从无关局部起镜，也不得在运镜结束后立即堆入来不及形成的复杂表演。
- 受困场面先建立可见封锁结构，明确阻挡者、出口和可行路径。人物可通过后退、回头、视线搜索或尝试移动依次检查退路，镜头按其注意力揭示阻碍；确认无路后再回到主要对手。不得只用对白宣告受困，也不得让保镖或群像无依据地改变位置。
- 持续性道具可作为对白和关系变化的节奏标点，但每次使用都须继承持握、燃烧／开启／破损等当前状态，并承担观察、施压、停顿、回应或动作触发中的实际作用；不得重复同一动作只为填补对白间隙。
- 场外人物入场前，先在现有构图中保留可进入的空间和方向；由门、脚步、声音或场内人物视线转移预告入口，再让新人物沿同一方向出现并完成从进入、发现目标到靠近的速度变化。不得无预告切到人物已经抵达目标面前。
- 多人场景建立“触发接力”：前一人物的对白、动作或状态变化应成为后一人物观察、移动、回应或执行的明确原因。每次接力都改变信息归属或行动责任，不能把多人拆成互不关联的轮流表演。
- 关键道具可建立贯穿叙事单元的状态线，核对其进入画面、持有、递出或移动、是否被接触或接受、最终归属和结束位置。相同道具只有在动作状态、归属或剧情结果已经改变时才可再次成为镜头主体；开头与结尾的道具呼应必须呈现变化后的结果，不拍无状态变化的重复特写。
- 人物离开后保留在场的道具、空位或其他既有结果可作为结尾落幅，但必须直接承接此前动作并帮助观众确认选择、未完成事项或关系结果；不得为了象征意味新增原文没有的遗留物，也不得替剧情强行解释唯一含义。

## CAM-01 单镜可执行性

- 每镜只承载一条连续、可追踪的摄影机路径和一个主体动作或反应；移动机位可沿该路径改变位置、角度和构图，但不得在单镜内无承接跳成另一套摄影机路径。并列信息只有在相互独立且需要分别看清时拆镜，不按标点机械切分。
- 只写摄影机可见、可听、可执行的内容，不解释画面已经表达的含义。
- 每个动作、微动作、接触点和关键道具必须落在当前景别与构图能够清楚覆盖的范围内。拍不到且不重要的内容直接删除；剧情或表演确需看清时，扩大景别或拆成有原文／延续对白承载的特写，不得在画外描述无效动作。
- 随原文信息推进，连续镜头应提供新的可见信息、观察对象、动作阶段、情绪落点或认知结果。长旁白或长对白先按语义、动作、情绪和信息转折划分视觉节点；相邻节点若能由同一条连续摄影机路径和画内调度完整承载，可以保留长镜头，否则在注意力、动作、信息或关系重心变化处选择自然硬切。不得让同一主体以同一景别、同一构图和同一观察关系跨越多个独立视觉节点而没有新的可见变化，也不得仅靠同一张脸上的连续细微表情变化承载长文本。
- 人物、多人调度和手持道具写清初始位置、移动方向、必要距离、接触关系和结束状态；相邻镜头从前镜结果继续。
- 镜头描述达到制作级：构图、机位、焦距、景深、运镜起止、调度与表演、前中后景、光源、道具、声音、连续性、时长和剪辑落点清楚；详细不等于合并多个动作。

## CAM-02 摄影参数与动机

- 镜头选择以画面表现力为第一优先级：围绕原文主动设计最能强化空间关系、人物调度、视点变化、景深层次、前景关系和情绪推进的画面陈述。不进行生成稳定性评级，不因变脸、复杂运镜、多人、遮挡、物理交互或背景动态等生成风险主动降低构思上限、简化方案或准备替代镜头。
- 只写真正影响生成的景别、机位、角度、焦距、景深、运镜起止和速度；光圈只在确需进一步约束景深时使用。
- 不使用摄影机品牌、型号、镜头厂商或镜头系列名称，也不用空泛“高端运镜”制造电影感。
- 长镜头、环绕、升降、俯冲等复杂运镜可直接用于最有表现力的方案，但必须实际参与空间揭示、关系变化、动作路径、注意力引导或情绪递进，不能只充当“电影感”标签。人物表演、对白口型、关键道具和跨镜连续性仍按剧情正确性与画面可读性准确组织，不作为压低镜头表现力的理由。
- 运镜必须服务原剧情信息、人物关系、动作路径或有依据的心理感知。可优先设计“一条主要空间轨迹＋一次次级构图变化”的复合运镜，并按先后阶段写清触发、速度、信息递进和落幅；两条以上主要轨迹互相竞争、明显多次变速或复杂空间穿行时再拆镜。人物脸、口型和关键道具优先于运镜。
- 具有顺序意义的运镜写成“起幅状态 → 前置动作完成 → 摄影机启动 → 移动路径与速度／幅度 → 揭示新主体或关系 → 落幅停止条件”；摄影机不得抢在触发动作完成前启动，也不得越过已经足以读清关系边界的落点继续游移。运镜的速度和幅度服从情绪与空间任务，克制或抽离场面可采用缓慢、受控的移动并以门槛、门框、立柱等固定锚点分隔双方，但不得把风格选择写成无依据剧情事实。

## CAM-03 摄影机驱动的空间几何

- 场景透视由摄影机位置、朝向、焦距及移动轨迹决定，不由人物朝向决定。
- 人物站位、视线、转身、进入、离开和移动路径优先用位置固定且已被当前镜头序列建立的场景锚点描述，如门、立柱、楼梯、出口、转角、窗户、围栏或固定陈设；没有合适场景锚点时，才使用位置已经建立、且相关动作完成前不会移动的人物作为参照。参照人物一旦开始移动便不得继续充当固定锚点。
- 空间调度按“从哪个锚点离开 → 沿哪条已建立路径移动 → 朝哪个锚点前进 → 最终停在何处或与谁形成何种距离”组织；相邻镜头继承同一锚点、路径和距离结果。不得只用“向左、向右、往前、往后”承担三维空间定位，也不得因换机位让人物的实际目标或行进路线改变。
- 画面左／右、人物画面朝向和视线方向只用于补充构图、轴线与视线匹配。必须使用画面方向时，须同时绑定场景锚点或稳定人物，例如“转向出口所在方向”，不能让二维画面方位取代真实空间关系。
- 固定机位时，人物转身或在画面内移动不得引发背景重构；背景可保持稳定，但人物与场景的尺度、遮挡和接触关系须随实际移动连续变化。
- 摄影机发生位移时，消失点、近远景视差、主体尺度和遮挡次序沿路径连续变化：近景对象位移通常大于远景对象，不能出现背景贴片、冻结或反向滑动。
- 摄影机原地摇摄只改变观察方向和画面覆盖，不重建空间；纯光学变焦改变构图与画面尺度，基本不改变透视关系。推轨、侧移、跟拍和环绕才产生对应的透视与视差变化。
- 单张场景参考图锁定可确认的布局、材质和陈设，不证明不可见角度。新角度保持已确认锚点，不补造与原图冲突的空间结构。

## CAM-ACT 明显动作的受力与收势

- 起身、转身、奔跑、拉拽、跳落、递接道具等明显动作，按“准备姿态 → 重心转移或发力 → 主要动作 → 惯性跟随 → 稳定结果”组织，只保留镜长内必要阶段。
- 短镜无法完成整条动作时，在发力、接触、离地、落地、交接或稳定等清晰阶段硬切；下一镜从该阶段继续，不得无依据复位、跳手、跳位或失去接触关系。
- 动作幅度、受力方向、身体重心和道具反馈服从人体工学与物理逻辑，不靠加快动作把复杂链条塞入短镜。
- 微表情和轻微手指、嘴角、视线变化不机械套用完整受力链。
- 砸击、推倒、冲向目标等强动作先让人物通过视线、转身或移动锁定真实目标，再表现准备、发力、接触和结果；强动作完成后若转为命令或下一行动，应由人物转向执行者、改变手势或视线完成行动责任交接。
- 命令类剧情须建立“发令者锁定执行者 → 指令出口 → 执行者接收 → 可见执行起势或结果”的链条。执行者拿起电话、移动或操作道具等镜头只有在证明命令已生效、推动阻止行动或改变局势时成立，并继承道具初始位置与动作阶段。
- 多人专业处置先区分普通人员、近距保护、远距控制、出入口封锁、监控支持和现场指挥。异常触发后按“发现 → 准备 → 锁定 → 判断阻碍 → 推进或停止 → 新警戒状态”完成接力；没有介入时必须让射线遮挡、人质接触、空间阻碍、既有封控仍有效或指挥者暂缓等原因进入画面。
- 武器或控制装备写清持有人、持握手、枪口／作用方向、安全射线、进入戒备的触发、未使用原因和落幅状态，并跨镜继承。装备不得只作装饰；也不得凭外观补造药剂、能源、自动识别或其他未确认功能。
- 蛇尾、触手、翅膀、机械臂、长发、绳索、锁链等会与人物、道具或空间发生接触、缠绕、拖拽、支撑或施力的连续结构，建立“来源位置 → 接近路径 → 首次接触 → 固定／抓取结构 → 发力主体与方向 → 受力反应 → 移动路径 → 结束状态”动作链。设计与审核须能全程追踪；单镜只写当前阶段，跨镜用接触点、方向、受力和动作阶段承接。
- 一个构图无法清楚呈现来源、接触、施力或结果中的关键变化时拆镜，即使总时长低于4秒也不得合并。修复优先补足已确认状态、拆动作阶段或拆生成段，不以降低画面复杂度作为默认方案。

## CAM-04 跨镜连续性

- 跨镜动作按“起始状态 → 触发 → 可见变化 → 结果状态”拆分，每镜只完成一个主要变化，后一镜从前一镜结果继续。
- 连续性锚点至少核对：人物方向、身体重心、视线、接触点、持握手、道具位置、光源状态、动作阶段和声音延续。
- 连续行走、追随、退开或靠近时累计记录人物每镜的移动方向、步数或相对距离；后续景别、焦距和双人构图必须服从累计后的真实位置，不得默认人物回到原位，也不得用原地踏步、瞬移、背景压缩或重复停步掩盖距离失控。
- 回走、折返或重新靠近必须有原文及人物当时态度支持的交流动机，并据移动者判断关系主动权：主动回走可表达重新介入、质问或施压，追上对方则可能强化追逐或压迫；不得只为恢复方便构图而让人物机械复位。回走无需回到原始站位，只到达能完成当前交流且符合关系边界的距离。
- 对白可以驱动有动机的连续位移。需要将停步、转身、回走和开口组合时，优先让触发性台词落音促成人物停步，再让人物转身并在说话过程中完成必要移动；对白最后一个词、脚步停止和摄影机稳定可共同形成落幅。动作顺序、移动距离与对白时长须自然匹配，不得为了填满对白让人物无目的来回行走。
- 摄影机跟随此类位移时写清起幅中的停点和朝向、运动过程中人物与对手的距离变化，以及落幅中的最终站位和对峙构图；下一镜从该最终距离承接。人物说完后若仍需继续移动，必须有新的剧情动作或关系变化支持。
- 多层空间穿行、多人接力、复杂脱穿衣或连续跨越按动作阶段、信息变化和最佳画面节奏决定是否拆镜；每镜明确结束状态并由下一镜连续承接。
- 可用推、拉、摇、移在前镜内部提前揭示下一镜主体、共同方向或动作落点，再于构图和动作稳定处硬切；这属于运镜引导的硬切衔接，不改变全片硬切规则。
- 对话、动作、追逐、群像或单人方向镜头先按 [axis-line.md](../libraries/axis-line.md) 识别关系轴、运动轴或方向轴及摄影机所在侧。默认守轴；只有满足该库规定的目的、方法、触发和重锚要求时才可换侧。

## CAM-05 切镜资格与序列观感

- 在不增加无效切镜的前提下，让镜头序列形成有意义的视觉变化：可改变空间层次、观察主体、景别跨度、机位高度、视点依附、前景关系、运动状态或动作阶段。丰富度必须来自新信息与新关系，不来自同类正反打、相似景别或无动机运镜的数量堆积。
- 先按完整表演和叙事单元设计镜头，再在视频提示词与剪辑执行阶段按 `timing-segmentation.md` 核算正式音频、工具边界和最终镜长；不得为平均分配时长、逐句对齐或展示更多机位而切镜。故事画面阶段不以秒数反向决定镜头数量。
- 每次硬切至少须改变一项足以影响观众理解或注意力的核心变量：观察主体、信息归属、人物关系重心、动作阶段、情绪方向、认知结果或空间关系。只增加眨眼、抿嘴、继续注视等轻微变化，不足以单独取得切镜资格。
- 相邻镜头若主体、轴线、机位高度、观察方向和景别相近，仅改变肩位、焦距数值或轻微构图，不视为有效变化；须合并，或改成有明确目的的景别跃迁、角度变化、动作触发、观察对象变化或空间重建，避免近似构图跳切。
- 同一主体、相近景别、相近姿态或同一动作阶段的连续硬切，至少须在观察对象、信息归属、人物关系、动作阶段、情绪方向、机位方向、构图重心或空间关系中产生一项观众可辨认的变化。发现近似跳切时依次判断：删除切点是否无损；能否改变观察关系、信息归属、动作阶段或关系重心；能否调整景别、机位高度／侧别、构图、前景或运动状态；最后才单纯增加角度差。所有修正服从关系轴、运动轴、方向轴、视线、人物位置、动作和道具连续性。
- 有明确叙事目的的跳切、对应锚点清楚的匹配硬切，或同一主体发生可见认知、权力、状态及时空变化时，可保留近似构图切换；须写明目的且让观众从画面看到变化，不得以“风格化”掩盖无效切镜或生成错误。例外仍使用直接硬切，不改变全片剪辑方式。
- 同一人物的连续对白或连续情绪优先保留主表演镜头，让呼吸、停顿、视线和表情在镜内积累。只在台词意义转折、关键动作发生、倾听者形成重要独立反应或关系重心改变时切出；切到倾听者时不得只展示无新增意义的静默注视。
- “连续拍同一张脸”指相邻镜头都把同一人物面部作为主要视觉信息；它覆盖特写到特写、近景到特写、中近景到近景以及过肩到单人近景等组合，不按景别名称机械判定。若第二镜没有新增认知、决定、情绪阶段、注意力、博弈状态、动作结果或关系变化，删除或合并切点后几乎无信息损失，即为无效连续拍脸。
- 持续近景／特写只有在具有明确戏剧目的且节制使用时成立，包括隐秘心理、心理压迫、对峙博弈、局部情绪高潮、单镜面部情绪流转、抽离麻木或项目明确采用的纪实表达。每次使用都须能回答“为何此刻必须读脸、面部发生何种可见变化、对应哪个节点、上一景别为何不足、何时完成任务并退出”；无法回答即视为惯性选镜。
- 有效连续拍脸默认同时具备新的戏剧任务和可辨识的视觉组织变化。重大认知、决定或情绪爆发可用克制视觉变化突出表演，但纯景别、焦距或小角度变化不能单独取得切镜资格；对白较长也不能成为轻微推近或换角度的理由。
- 近景／特写按相邻镜头、当前场景和整集三层审核，并跨生成段连续审看。不设机械数量配额；若普通信息与高潮使用同等强度、连续节点都依赖面部、空间未建立、高潮前没有收紧余地、高潮后没有释放，或环境、肢体、道具与他人反应长期被闲置，即判定使用失去节制。多人、移动、道具交互或方向变化场景须先以空间基准镜头、双人构图、运动路径或既有清晰锚点建立位置、距离、朝向、关键道具和行动通道；心理封闭可主动剥离空间，但须有明确主观目的。
- 心理对峙允许来回切脸，但每次切换须呈现话语控制权转移、识破或化解、视线压迫或回避、情绪防线裂口、沉默改变关系，或事实／道具介入等博弈状态变化；人物轮流说话不自动取得反打资格。
- 一句旁白可由同一连续镜头准确覆盖多个相连节点；“逐节点充分视觉覆盖”不等于“逐节点必须切镜”。需要拆镜时，各镜分别承担不可合并的新视觉信息，不能用多个相似反应镜头重复表达同一状态。
- 定稿时连续审看镜头序列，而非只检查单镜合规。若删除某一切点后不损失剧情、信息、情绪、动作可读性或节奏，则该切点属于无效切镜，应删除；若硬切前后形成同主体、近似尺度和近似姿态的轻微跳变，应合并或重设切点。发现问题后直接选择最有表现力且合规的方案，可合并或删除镜头、改拍视线目标／动作结果／关键道具／人物与空间关系／有效反应、重建叙事转折、调整镜长与切点、改变同期与画外连续对白归属、重做当前序列或调整相邻段界；不得新增原文没有的事实、人物、道具或剧情动作。修正后重新执行相邻、场景、整集三层审核以及原文、时长、动作、连续性、轴线和资产回归，持续迭代至全部通过；合规方案效果相近时自行选择，不因审美分支停下询问。

## CAM-06 落幅、起幅与镜间承接

- 每个镜头在设计时同时确定落幅和下一镜起幅。落幅记录切出瞬间的主体位置、景别、身体朝向、视线方向、动作阶段、画面重心、前后景关系和必要声音；下一镜从这些可见状态中选择需要继承的锚点，不得把人物、动作或道具复位后重新开始。
- 关系边界或人物分隔是落幅任务时，必须明确“动作完成 → 运镜揭示 → 固定空间锚点读清 → 摄影机停止”的顺序；落幅停止后保持门槛、门框、立柱、出口等锚点对双方的分隔，不用继续横移破坏构图重心或把克制的离开误读成追逐、怨恨或和解。
- 制作参考区中每镜必须把承接关系记录为可执行信息：镜头结尾明确“落幅于<可见结束构图与状态>”；除生成段末镜外，紧接着写“下一镜从<继承的主体／动作／视线／方向／构图重心／声音锚点>承接”。下一镜起幅必须兑现该锚点，再发生新的动作或构图变化，不能只在前镜单方面声明承接。可提交提示词区只保留模型需要执行的可见动作与状态，不写上述承接句。
- 制作参考区的生成段末镜写“下一段从<结束快照中的可见锚点>承接”；下一生成段的初始空间状态和首镜可见起幅必须共同兑现。原文明示跳时、换场或时间跳跃时，也要写清前镜落幅、新段入场状态及由何种信息关系完成硬切，不能把转场当作免检断点。
- 硬切须使用有剧情依据的承接关系：动作承接、视线承接、方向承接、构图重心承接、声音承接，或为强调信息与情绪转折而设计的明确景别／角度反差。承接不是要求前后画面相似；相似构图若没有新意义仍属于无效跳切。
- 普通动作在稳定结果处落幅；需要动作匹配时可在动作方向和阶段清楚的过程中切出，下一镜从同一方向、同一阶段或紧接的后续阶段起幅。不得在动作含混处切断，也不得让下一镜重复前镜已经完成的动作。
- 对话反打以前镜说话者的视线、停顿、转头、抬眼或台词意义落点引出下一主体；下一镜先继承被看者已经存在的姿态和反应阶段，再产生新的可见变化。不得每次反打都让人物从中性表情重新表演一次。
- 镜头末尾若用留白、前景、人物出画方向或道具位置引导观众视线，下一镜的核心主体应在对应区域或运动方向上接住注意力；有意改变画面重心时，必须由信息反转、关系变化或动作方向变化提供动机。
- 落幅与起幅设计不得新增原文没有的动作、物件或剧情，只能组织已有内容。生成段边界同样执行本规则，并把最后一镜落幅写入下一段的开始快照。

## CAM-07 动静转换的节奏过渡

- 静止镜头不得直接硬切到已经处于高速或大幅运动中的镜头。两镜之间须建立可见的运动动机和速度梯度，让观众先感知动作将要发生，再进入主要动态。
- 优先在静止镜头落幅前加入原文支持的起势，例如视线转向、身体重心前移、抬手、转身准备或目标进入注意范围；下一镜从该动作已经启动的连续阶段起幅，并自然加速到主要动作。
- 前镜无法容纳起势时，可使用有旁白、同期对白或画外连续对白承载的桥接镜头，表现动作触发、局部发力、脚步启动、手与道具接触或运动方向建立。桥接镜头必须提供必要的新信息，不得成为只为过渡而存在的空镜或无效切镜。
- 无法增加独立桥接镜头时，动态镜头必须从准备姿态开始，在同一镜头内完成“静止／微动 → 起势 → 加速”，不得起幅即进入无来源的高速状态。
- 过渡仍使用硬切；不得用淡入淡出、叠化或转场特效代替动作承接。遮挡、缩放或甩镜可以在前镜内部建立匹配点，但切点必须明确写为直接硬切，下一镜从对应锚点起幅，不生成连续变形或无剪辑转场。所有起势与桥接动作只能组织原文已有行为，不得为顺滑新增剧情。
- 动态镜头转入静止状态时同样建立速度梯度：对白或主要动作先完成，最后一个手势、脚步或身体惯性自然收束，随后呼吸和视线落定，再进入安静观察或下一人物反应。不得从快速说话、手舞足蹈或奔跑状态直接切成完全静止姿态。
- 动态停止可用于把叙事主动权交给另一人物；前镜落幅须让观众看清谁停止、为何停止以及视线落向何处，下一镜再承接被观察者的新反应，不能把“突然不动”当作无动机的节奏变化。

## CAM-ENV 必要环境动态

- 雨、雪、风、烟雾、火焰、流水、车辆运动或闪烁灯光等环境动态直接影响剧情、人物状态、道具状态或跨镜连续性时，不能只在整集场景资产中声明。每个受影响镜头还须写出当前构图内可见的动态本体，或它对人物、服装、道具、地面和背景造成的可见结果。
- 逐镜只保留当前景别确实能看到的证据：全景可呈现环境范围与运动，中近景可呈现背景动态和人物所处边界，特写可呈现湿发、水珠、衣料摆动、烟尘附着等直接结果；不得机械复制整段场景描述，也不得写入构图拍不到的状态。
- 人物进入屋檐、门廊、车辆或室内等遮挡区域后，区分“环境仍在持续”和“人物不再直接受其作用”。例如人物避入屋檐时，可见背景雨幕、檐口落水与湿衣滴水，但不得继续描述雨水直接落在人物身上。
- 环境动态没有剧情触发的变化时，其强度、方向、覆盖范围及对人物和道具造成的结果跨镜保持一致。任何增强、减弱、停止或作用区域改变都须有可见触发，并由后续镜头继承。

## CAM-SNAP 生成段首尾状态快照

- 每个生成段内部记录结束帧快照：机位侧别与高度、观察方向、焦距范围、人物位置与朝向、姿态与重心、视线、接触关系、持握手、道具位置、光源状态、动作所处阶段，以及跨切声音的来源和延续范围。
- 下一生成段必须从该快照开始；其中人物与道具进入本段时同时成立的位置、朝向、距离、持有、接触和状态写入初始空间状态，其他承接变化由首镜兑现。快照不得变成重复的整集资产清单。
- 首段记录初始状态。只有原文明示跳时、转场或状态变化时才允许不继承，并须写清新的时间、地点和入场状态。

## CAM-CUT 全片硬切

- 镜头之间、生成段之间以及片头片尾的画面全部使用硬切。禁止淡入、淡出、叠化、溶解、渐隐、渐显或任何连续变形式转场。遮挡、缩放、甩动或旋转只允许作为前镜和后镜各自内部的动作与构图，二者之间仍须明确直接硬切并兑现承接锚点。
- 动作、视线、方向、声音或构图匹配只用于选择自然的硬切时机，不改变硬切方式。
- 运镜可以在单镜内部为下一镜建立主体、方向和构图关系；运镜结束后的镜间连接仍须直接硬切，不得把推拉摇移写成转场特效。
- 构图匹配只帮助硬切可读性，不得为匹配剪辑新增原剧情没有的象征物、形态变换或变形对应。
- 每镜保留“连续性与剪辑落点”，写清继承状态、主要变化、结果画面、硬切位置及必要声音的承接。
- 单镜内部有剧情动机的甩镜或快速运动仍可使用，但不得用来遮盖切镜或伪装成非硬切转场。
- 硬切只约束画面。有依据的对白、呼吸、拟音或必要声音可以跨切延续，但必须写明来源、说话者是否离画和结束落点。
