# 对白与表演模块

本模块是人物对白、情绪词、可见微动作、倾听反应和长对白切镜的唯一规则源。涉及明显身体动作或跨镜承接时，由中心路由同时加载 `shot-continuity.md`。

## PER-00 知情状态与情绪依据

- 设计每镜情绪前，先按前文、本集已发生内容和当前信息揭示顺序确认人物此刻“已经知道、尚不知道、误以为知道”的内容；同一句台词必须服从人物当时的信息差，不能把已知事实拍成初次发现，也不能提前表现后文认知。
- 情绪判断必须精确到当前关系语境。疑惑、无奈、嗔怪、讽刺、怜爱、觉得对方笨拙可爱等相近方向不得凭动作相似互换；制作参考可写有剧情依据的心理方向，再将其转译为对应表演。

## PER-01 对白主体

- 对白镜头以说话者为表演主体，写清沟通对象、视线、语气、音量、语速、停顿、重音、呼吸、口型、手势和身体重心；只取当前台词真正需要的信号。
- 倾听者只保留一个从既有状态发生的清晰反应，避免双主体同时堆叠动作。多人场景按剧情分层，背景人物保持克制，不要求所有人同时“情绪丰富”。
- 开口前加入符合情境的可见缓冲，如吸气、视线落定、下颌放松或嘴唇微启；话后保留必要的闭口、视线或呼吸落点，不机械重复眨眼。

## PER-02 情绪与连续微动作

- 制作参考可记录有剧情依据的完整情绪与心理判断。可复制提示词允许直接使用少量明确的情绪词或情感形容词作为表演方向，但每个词必须立即搭配按先后发生、且能被当前构图清楚拍到的微动作或可听声音变化；不得让抽象情绪词独立承担表演。
- 禁止心理活动、内心独白、不可见意图和无表演证据的抽象情绪结论。动作后不重复解释“这说明他／她……”。
- 细腻情绪优先使用呼吸变化、肩颈松紧、身体重心、视线、手指、嘴角和已有道具等少量信号递进。相邻正反打延续同一状态，可用“持续后停止”“收紧后松开”形成变化与硬切落点。
- 点头、摇头、伸手、回避视线等回应动作先建立与其含义一致的情绪和观察状态，动作完成后保留清楚的姿态、视线、口型或呼吸落点，避免机械回应。
- 明显情绪转向按“触发 → 形成 → 释放或外显 → 停止 → 新态度落定”选择必要阶段，不能让大笑、愤怒、恐惧等强状态无缓冲地瞬间切换成严肃、冷静或坚定；阶段过多且单镜无法看清时按有效变化拆镜。
- 人物从受压、惊恐或失控恢复到主动表达时，先让其看清当前处境，再用原文支持的呼吸、重心、视线或姿态变化表现自我稳定，最后开口；不得用一次深呼吸直接跳过尚未完成的情绪转变，也不得把整理情绪写成心理说明。
- 关怀转为愤怒、担忧转为报复等方向变化必须有可见判断依据：先观察或检查对方状态，再让所见结果触发呼吸、下颌、视线或身体方向变化，最后进入强动作或命令；不得从安抚动作直接跳到无来源的暴怒。
- 两名人物可通过有剧情依据的动作强度反差建立节奏，例如一方持续说话或比划，另一方以较少动作观察、克制或回应；反差须推进关系或喜剧／压迫效果，不要求每段对白都机械配置“一动一静”。
- 同一种表情方向多次出现时，每次必须处于新的阶段或含义：初次形成、压住后残留、再次被触发、主动释放或转为沟通回应。若相邻近景只重复相同笑意、含泪或皱眉而没有阶段变化，应合并；无意流露与有意识回应不得写成同一种机械表情。
- 面部确认可触发后续明显行动：先让人物通过目光、停顿或表情完成态度落定，再进入起身、靠近、挽手、离开等动作链。动作不得早于人物完成判断，也不得用未被画面建立的表情解释重大关系转变。
- 不为表演新增原剧情没有的道具，不堆叠近义形容词，不把所有微动作机械填满。

## PER-03 精简可执行表演

- 表演描述精确简短，只保留推动当前镜头的最少有效信号。
- 有实际变化时从“初始状态 → 触发 → 可见变化 → 收束状态”选取必要节点；多个独立触发、动作节点、情绪转折或认知阶段拆镜。即使镜长不超过4秒，只要单一画面无法自然看清这些变化，也不得以时长合规为由合并。
- 微动作只写先后与状态变化，不在镜头内部标注秒数、毫秒、持续时长或毫米级幅度；镜头整体起止时间仍保留。
- 明显起身、转身、奔跑、拉拽、跳落、递接等动作使用镜头连续性模块的受力与收势规则；普通眨眼、抿嘴、视线和手指微动作不机械套用完整受力链。

## PER-04 长对白与画外连续对白

- 对白总时长不设上限。长对白可切到能推进当前关系的倾听者反应、说话者动作、过肩镜头或已有道具特写。
- 先按自然语速、停顿和情绪核算对白可说完的时间，再按语义节点安排镜头；不得用过快语速把多个完整信息压进短镜，也不得仅为延长对白让同一角色保持单一说话画面。一个长句包含地点、原因、动作或结果等多个信息时，可分别用说话者、道具或有原文依据的回忆画面承载。
- 只在自然语义停顿、视线变化或动作触发处硬切，不为变化景别随机切镜。
- 说话者离画后在“人物表演”标注“人物名画外连续对白”，继续使用同一参考音频并保持语速、音量、停顿和空间声场；倾听者不匹配口型。
- 画外连续对白可用于并置说话者态度与倾听者正在承受的身体反应、空间限制或认知变化；使用时必须让画面提供比说话者口型更重要的新信息，不能只为避免拍摄说话者而任意切走。
- 切到倾听者时只写一个从既有状态发生的可见变化。重要对白优先在原镜话后余量中保留闭口、视线、呼吸或倾听者反应。
- 只有仍在延续的对白或对应旁白能够承载独立反应镜头；不得新增只靠静默、环境音或拟音承担的反应空镜。
