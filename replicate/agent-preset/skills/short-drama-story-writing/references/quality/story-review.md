# 故事稿审核

本文件是故事阶段审核判定的唯一所有者。输入为可唯一识别的候选故事稿、当前原剧本、目标集前后文及导演确认结论；输出为绑定该候选版本的新增内容追踪、缺陷账本和审核结论。审核只验证与定位，不在审核遍历中顺手改写候选稿。

## 审核门

1. **原文保护**：剧情结论、人物关系、关键事实、事件顺序、因果和信息揭示顺序保持一致；原对白逐字保留；没有提前剧透、重复后文事件或把比喻旁白变成事实。
2. **新增合法**：每处新增同时满足摄像机可见、符合人物当时所知、能从上下文推出、删除后不改变原剧情结论；新增身份、能力、道具功能、地点规则、对白或关键事件均为失败。
3. **故事动力与正确情绪**：每个重要场景按“事件触发 → 冲突显形 → 人物目标 → 具体阻碍 → 当前策略 → 策略变化 → 反应波动 → 空间张力 → 关键信息 → 关系权力变化 → 不可逆节点 → 场景结束状态”推进，并至少改变信息、关系、目标／策略、风险／阻碍或情绪／行动状态中的一项。人物在原文支持时主动选择；重要段落按“起始状态 → 可见或可听触发 → 主导情绪 → 被压住的次级情绪 → 人物选择 → 决定性动作 → 对方反应 → 新状态”形成情绪因果脊柱。情绪依次服从原文、人物当时知情状态、眼前触发及人物目标与恐惧；强度与事件、性格和关系相称。按 [导演叙事判断总纲](../../../short-drama-director/references/narrative-directing-principles.md) 检查重要节点的细节功能、不可提前揭示项、演绎空间与观众空间；留白不能掩盖已发生事实或状态结果。
4. **空间状态**：人物进出、位置、方向、持物、装备状态和环境运行连续；制度空间、功能人员、指挥链、介入或不介入原因与原文危险等级相称。
5. **组织、回收与动作价值**：长旁白由连续小故事推进；原文支持并列事实时才使用蒙太奇，且具有递进、对照或回收。重复尝试改变方法、风险、距离、公开程度、代价、信息或关系；重要信息改变人物或观众的认知、情绪、选择、关系或行动。重要对白具有沟通行动和可追踪的权力变化；潜台词可由原文、动机和知情状态推出。新增无对白画面均有当前旁白句或语义块承载，对白期间的无声反应由当前对白直接触发。有意义的动作、道具状态、空间关系、表演习惯与视觉母题得到准备或回收。
6. **场景、高潮、结尾与下游转化**：场景进入和退出围绕首个有意义变化与核心状态改变，场景间具有因果或可兑现的跳跃锚点。环境反应只在主事件进入其感知、职责要求介入、反应会改变主角选择／风险／空间或原文明确需要群体态度时出现。高潮落在不可逆行动、选择、揭示或拒绝；结尾在最终关键变化得到清楚反应后停止。正文自然连贯、具有情绪感染力，不是动作清单或技术审核表；正文后包含完整的故事动力传递摘要。

## 新增内容追踪与缺陷账本

先列 `新增内容｜对应原文旁白／对白或确认依据｜服务目的｜删除后是否改变剧情｜判定`，覆盖每一处故事化补充。每个实际缺陷再记录：`ST-编号｜失败／警告／建议｜候选稿定位｜权威依据｜问题｜影响｜修正目标｜状态`。以下为失败：重要场景没有状态变化；事件没有进入冲突或后果；冲突停留在抽象气氛；反应缺少触发和方向；空间调度无依据改变事实、关系或结果；原文支持主动选择却把人物写成被动说明；重要信息没有认知、情绪、选择、关系或行动后果；长旁白只有并列画面而无原文支持的推进组织；重复尝试没有策略、风险、代价、信息或关系变化；重要对白没有沟通行动而形成死对话；高潮只有强烈表达而无决定性结果；场景转换或状态连续性断裂；细节无事实、关系、情绪、线索或后果功能却占据叙事位置；以留白为由掩盖已发生事实；以及其他硬约束违反、原文篡改、无依据新增、不可拍内容、情绪依据或强度失真。原文支持更清楚的权力转移但表达偏弱、可用的准备回收未充分利用、场景进入过早或状态改变后拖延、画面虽对应原文但没有提供互补信息，均为警告。增加非必要母题、对照或类型化区分只属建议。不得用总分或平均分抵消失败。

## 修正与复审

1. 锁定候选版本，完成新增内容追踪和六道审核门，先登记全部缺陷再修正。
2. 执行性缺陷可在已确认故事化授权内自动定点修正，包括可见动作、衔接、空间连续性、原文映射和表演证据；涉及情绪方向、场景进入／退出、视觉母题、人物主动性或其他创作选择时暂停请导演确认。任何修正都不得改变原文或扩大授权。
3. 逐项关闭缺陷后，对原对白、剧情锚点、新增内容、前后文、场景推进图、情绪因果脊柱和全部六道审核门重新执行全量复审；仍有失败则继续“修正 → 全量复审”，不设固定轮次。
4. 零失败且所有警告均有原因、影响和处理结论时，报告“审核通过”；涉及创作选择或授权边界的警告须经导演确认。否则保持“审核失败”。
5. 详细报告单独保存并绑定候选故事稿版本，列出实际读取文件、新增内容追踪、缺陷账本、每轮修复、复审证据和最终结论；故事正文不承载技术审核记录。
6. 只有审核通过且包含故事动力传递摘要的故事稿才能升级为当前有效交付并供下游默认读取。
