# AI短剧摄影机与镜头库

本库只提供镜头用途、生成稳定性和替代方案；剧情、时长、空间和硬切纪律服从规则模块。稳定性：高＝通常可直接生成；中＝简化背景、人数和动作；低＝优先拆镜或后期完成，并准备稳定替代。

## 景别与视角

| 镜头 | 主要用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 大全景 ELS | 定场、地理关系、人物与环境比例 | 高 | 不承担精细口型 |
| 全景 WS | 全身动作、人物与场景位置 | 高 | 明确左右、前后和行动方向 |
| 中景 MS | 常规叙事，兼顾动作与表情 | 高 | 默认叙事主力 |
| 中近景 MCU | 日常对白、轻微情绪变化 | 高 | 保留视线空间和对话对象方向 |
| 特写 CU | 关键台词、反应、信息落点 | 高 | 一镜只突出一个变化或物件 |
| 大特写 ECU／微距 | 眼睛、嘴唇、指尖、关键道具 | 中 | 避免复杂动作，必须有剧情依据 |
| 主观视角 POV | 角色所见、信息揭示、短时沉浸 | 中 | 写清视线来源，避免无依据晃动 |
| 半主观视角 | 贴近角色感受，同时保留第三人称空间判断 | 高 | 贴近其身高、位置和视线，保留肩部、后脑、身体边缘或运动痕迹；明确视点依附对象，不与普通过肩镜头混用 |
| 过肩 OTS | 对话关系、倾听反应、权力距离 | 高 | 锁定肩位、视线轴和口型归属 |

景别先服从叙事目的和必须看清的内容，不机械套用固定身体裁切比例。动作、接触点或道具是否入画会影响生成时，明确画面覆盖范围，并避免在人物关节附近形成生硬裁切。

## 机位与角度

| 镜头 | 可服务的剧情动机 | 稳定性 | 稳定替代 |
|---|---|---:|---|
| 平视 | 客观、平等、自然交流 | 高 | 默认使用 |
| 轻微低角度 | 权力上升、压迫或高光 | 高 | 中近景轻仰，不必极端 |
| 极低仰拍／虫蚁视角 | 极端压迫、脚步冲击 | 中 | 贴地局部特写 |
| 轻微高角度 | 脆弱、受困、空间劣势 | 高 | 中景轻俯 |
| 垂直俯拍／顶视 | 阵列、路径、困局、地面动作 | 中 | 高位斜俯全景 |
| 荷兰角 | 明确的失衡、眩晕或失控 | 中 | 小角度倾斜，不作普通紧张装饰 |

角度是候选表达，不是固定情绪公式。先核对人物真实位置、空间高差、视线关系、剧情信息和当前权力变化，再决定是否用角度强化有依据的情绪；不得为了表现某种情绪破坏已经建立的空间关系。

## 构图

| 构图 | 用途 | 稳定性 | 注意 |
|---|---|---:|---|
| 三分构图 | 常规叙事、保留视线与行动空间 | 高 | 默认构图之一 |
| 中心／对称 | 仪式、秩序、权威、刻板压迫 | 高 | 必须有空间对称基础 |
| 前景遮挡／Dirty Frame | 偷窥感、纵深、关系阻隔 | 高 | 不覆盖关键脸和道具 |
| 窥视构图 | 监视、偷听、隔离或受限观察 | 中 | 明确观察者或合理受限机位；遮挡须有叙事作用且不妨碍关键信息，不借遮挡转场 |
| 框中框 | 束缚、隔离、观察关系 | 高 | 使用真实门窗、框架或镜面 |
| 引导线 | 空间方向和人物目标 | 高 | 线条必须真实存在 |
| 留白 | 孤立、等待、空间压力 | 高 | 必须有对应旁白或延续对白承载 |
| 黄金比例／螺旋 | 大场面视觉引导 | 中 | 作为构图结果，不写玄学参数 |
| 功能性空镜 | 原文中的环境、时间变化、事件结果、道具状态或人物离场结果 | 高 | 必须由对应旁白或画外连续对白承载；不用纯抒情、装饰、转场或填时长空镜 |
| 上下分屏 | 手机端明确要求的并行信息 | 低 | 仅由导演或项目明确启用；上下画面分别设计生成并后期合成，写清时间关系、信息主次和同步点 |

## 焦点与景深

| 技法 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 浅景深 | 对白特写、隔离杂乱背景、关键物件 | 高 | 明确焦点，避免多人同时表演 |
| 大景深 | 空间关系、多层人物信息 | 高 | 控制主体数量，写清前中后景 |
| 焦点转移 Rack Focus | 前后景线索揭示、注意力转移 | 中 | 只做一次，主体位置固定 |
| 柔焦 | 有原文依据的回忆、梦境、柔和质感 | 中 | 不用于普通美化，不损失人物识别 |
| 主观虚焦／失焦 | 原文明示的昏厥、醉酒、视力异常、意识模糊或认知变化 | 中 | 明确感知主体；可在镜内失焦后硬切，或硬切至持续失焦的下一镜再恢复；不作模糊叠化、场景融合或隐藏变形 |

失焦期间不承担必须看清的口型、人物身份、关键线索或剧情信息；切换瞬间仍为直接硬切，虚焦只是镜头内部或切点两侧的画面状态。

## 基础运镜

| 运镜 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 固定机位 | 对白、克制情绪、清晰动作 | 高 | 强表演场景优先 |
| 缓慢推进 | 信息或情绪逐渐收紧 | 高 | 写清起止景别与速度，只推进一次 |
| 缓慢后撤 | 关系疏离、揭示环境、结束段落 | 高 | 后景信息必须真实存在 |
| 平移／摇摄 | 跟随单向动作或揭示相邻信息 | 高 | 单方向、单速度，不来回扫 |
| 升起／下降 | 从局部扩展空间，或从环境收束到目标 | 中 | 写清起幅、落幅和新增信息；不承担复杂群体动作或关键口型，不稳定时拆成高位与地面镜头硬切 |
| 轻微手持 | 纪实、奔跑、受控不安 | 中 | 幅度轻，不用于关键口型特写 |

## 低变脸风险模型的条件性提权

- 当前项目已确认所用模型的人脸一致性可靠时，提高缓慢侧移揭示、沿视线单向摇摄、克制推拉、过肩前景遮挡、侧移跟拍和基础半环绕的选用优先级；不再仅因旧模型的变脸风险退回固定机位。
- 提权不等于无条件使用。运镜仍须服务信息揭示、人物关系、动作路径或情绪递进，并写清摄影机起止位置、轴线侧别、运动方向、落幅构图及硬切点。
- “侧移揭示＋推进回应”可用于相邻人物的对话衔接：前镜从说话者或观察者单人构图缓慢侧移，揭示另一人物或形成过肩前景并建立轴线；稳定落幅后硬切，后镜保持同侧机位，缓慢推进接住对方反应。跨镜保持视线方向、人物朝向、姿态与动作阶段连续。
- 仅因人脸漂移而受限的操作可提权；复杂空间重构、多人粘连、高速运动、连续大遮挡、物理交互、口型或可读文字仍按各自风险控制。极速360度环绕、高频变焦、复杂穿障及多人复杂调度不得据此提权。

## 跟拍与环绕

| 运镜 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 贴身跟拍 | 行走、奔跑、紧迫行动 | 中 | 单主体、清晰路径、背景简化 |
| 贴地跟拍 | 脚步、速度、落地动作 | 中 | 聚焦下肢，不同时要求稳定面部 |
| 低角度仰角跟拍 | 角色高光或威压移动 | 中 | 路径短，避免拥挤背景 |
| 穿障跟拍 | 空间穿行、追逐、遮挡节奏 | 低 | 最多一个主要遮挡节点，可拆镜替代 |
| 侧移跟拍 | 并肩行走、骑行、横向移动 | 中 | 锁定方向和人物间距 |
| 基础半环绕 | 从侧面过渡到正面、揭示状态 | 中 | 建议90–180度，不默认360度 |
| 低角度环绕 | 强烈高光或压迫 | 低 | 单人、短动作，准备固定替代 |
| 高空环绕 | 建筑、阵列、大场面中心关系 | 低 | 不承担面部或对白 |
| 极速环绕跟焦 | 极端动作高潮或失控 | 低 | 优先拆镜并后期加速 |
| 半环绕推进 | 独白或情绪逐步显露 | 中 | 口型复杂时改固定近景 |

## 变焦、俯冲与速度变化

| 运镜 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 缓慢光学变焦 | 不移动机位的注意力收紧 | 中 | 不与推轨同时使用，透视基本不变 |
| 急推／急拉 Crash Zoom | 突发信息、喜剧或强反应点 | 中 | 一次完成，时长短，有明确落点 |
| 希区柯克变焦 Dolly Zoom | 世界观崩塌、明确恐惧或震惊 | 低 | 单人中心、背景有纵深，可拆为推进加后期变焦 |
| 定点变焦摇镜 | 混乱中寻找目标 | 低 | 优先拆成全景加目标特写 |
| 跟拍高频变焦 | 纪实或极端躁动 | 低 | 不用于关键口型和资产锁定镜头 |
| 稳定超广角 | 大空间、建筑或群体关系 | 高 | 控制边缘人物畸变 |
| 高空平飞扫拍 | 地理建立、宏观移动方向 | 中 | 不承担细节剧情 |
| 稳定穿景推进 | 从门窗或走廊进入主要空间 | 中 | 路径简单、遮挡清晰 |
| 极速垂直／斜向俯冲 | 坠落、降临、竞速、动作高潮 | 低 | 单一落点，背景简化，优先拆镜 |
| 俯冲接贴地跟拍 | 高空到地面连续动作 | 低 | 拆为俯冲、硬切、贴地跟拍 |
| 单次慢动作 | 原文支持的撞击、泪滴、关键手势 | 中 | 只突出一个瞬间，不拖长对白 |
| 降格／加速画面 | 原文明示的时间压缩、重复劳动、连续琐碎动作、忙乱或喜剧节奏 | 低 | 优先后期处理；不承担同期对白、关键情绪、口型、复杂接触或须逐步看清的信息 |
| 快到慢／快慢快 | 动作峰值或落地节奏 | 低 | 后期优先，生成时保持动作连续 |
| 甩镜 Whip Pan | 单镜内突发转向、喜剧或追逐 | 中 | 单一方向和落点；不得遮盖切镜 |

组合两种以上主要运镜或明显速度变化时拆成连续镜头。摄影机移动时的透视、视差与遮挡服从镜头连续性模块。

## 对白叙事与回忆插镜

| 方案 | 适用信息 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 说话者当前表演 | 态度、请求、承认、当下关系 | 高 | 保留自然口型与话后落点，不连续堆积多个语义节点 |
| 道具承载的画外连续对白 | 对白核心落在已有物件、持握或交接 | 高 | 道具身份和状态跨镜一致，画外说话者继续同一声音 |
| 有原文依据的回忆插镜 | 对白明确叙述过去的具体动作或结果 | 中 | 只拍原文信息；无必要人物保持画外，避免新增模型与设定 |
| 画外来源进入、主体接取 | 抛入、递入、声音或物件从画外到达 | 高 | 写清进入方向、运动轨迹、主体准备、接触和收势，不必生成来源人物 |

- 回忆镜头标题的景别字段只写“全景／中景／近景”等实际景别，不把“短暂闪回”“回忆”“梦境”等叙事标签塞入景别名称；回忆属性由制作参考、场景状态和前后承接表达。
- 当原文重点是物件如何到达而非提供者身份时，优先让物件从画外进入并由主体接取，减少不承担信息的人物模型；不得删除原文明确要求出镜的人物。
