# 系列视觉语言

本文件拥有同项目多张宣传图、封面、角色卡和视觉参考的一致性与差异化规则。

## 共同语法

系列开始前记录当前有效的：

- 人物身份和时期造型；
- 时代、地域和媒介；
- 基础色板、材质和光线方向；
- 字体方向、标题层级和安全区；
- 固定场景与道具；
- 禁止出现的文字、标志和剧情实体。

共同语法是系列边界，不要求每张复制同一构图、姿势或背景。

## 单张主题

- 每张只承担一个主要传播主题，如危机守护、身份暴露、关系对抗、日常暗涌、追逐、囚禁或记忆；主题必须由当前剧情支持。
- 用事件、关系距离、观察位置、色彩重心或空间阻隔制造差异，避免所有图片退化为相同的双人正面摆拍和装饰背景。
- 每张独立生成和验收；不得用上一张已漂移结果作为下一张唯一身份参考。

## 系列检查

- 一致：人物身份、时期、固定服装、世界规则、固定场景／道具、标题体系。
- 可变：剧情瞬间、主体关系、景别、观察方向、情绪重心、前景关系和传播主题。
- 系列图之间应能看出共同项目归属，同时每张在缩略图尺寸下仍有不同的视觉中心。
