# 剧本分析审核

本文件是分析阶段审核判定的唯一所有者。输入为三份候选报告、交接说明、JSON索引、当前原剧本、前后文及导演确认结论；输出为绑定候选版本的缺陷账本和审核结论。

## 审核门

1. **原文与场景覆盖**：所有原场号、戏剧节拍、关键事件、关系、时间、知情状态、信息揭示、反转、钩子和剧情债务均进入分析，重要判断绑定原文位置。
2. **全局链条**：因果、信息、情绪、关系／权力、时间、空间和道具链闭合或进入账本；逐场结果回写整剧模型。
3. **证据等级**：只使用原文明示、前后文可唯一推出、导演确认、临时工作假设和分析判断；导演确认具有可定位记录与明确作用域，后两类不冒充事实或导演确认。
4. **原剧情权限**：最小方向不改变对白、场次顺序、剧情事实、人物决定、关系结果、反转、结局或时间线，也不自动授权下游实施。
5. **推定可撤销**：阻断已有受约束推定；证据、替代解释、影响、失效条件和重跑范围完整，未使用商业判断或新增剧情元素；已升级假设保留原ID、确认记录、作用域、新事实ID和全量复审证据。
6. **报告职责隔离**：编剧、制片和导演报告共享事实且互不越权；制片便利不改剧情，导演手册不锁定逐镜。
7. **问题状态**：问题具有等级、影响、最小方向、禁止变化、责任技能和合法状态；无状态按禁止实施处理。
8. **下游合同**：交接说明与可解析JSON一致，ID和权限路由完整；临时假设未进入正式下游字段。
9. **商业隔离**：未明确要求时不存在商业文件；存在时不进入主分析、交接索引、创作结论或下游路由。
10. **影响与完成**：局部变化沿依赖图更新真实影响范围；全部报告、交接文件和未受影响结论全局复核一致。

## 缺陷账本

每个实际缺陷记录：`AN-编号｜失败／警告／建议｜候选稿定位｜权威依据｜问题｜影响｜修正目标｜状态`。硬约束违反、关键原文遗漏、事实越权或内部矛盾均为失败；资料确实不足但不阻断安全分析时为警告；纯增强项为建议。不得用总分或平均分抵消失败。

## 修正与复审

1. 锁定全部候选文件并完成十道审核门，先登记全部缺陷再修正。
2. 只修改缺陷指向的分析内容，不改原剧本或导演确认结论。
3. 逐项关闭缺陷后重新执行全部十道审核门；复审不得只检查改动段。
4. 零失败且所有警告均有处理结论时，报告“审核通过”；否则保持“审核失败”。报告列出候选版本、实际读取文件、缺陷账本、复审结果和最终结论。
5. 只有审核通过的三份报告、交接说明和JSON索引才能整体升级为当前有效交付并供下游默认读取；商业旁路不参与升级。
