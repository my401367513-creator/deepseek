# 制图工作流

本文件拥有制图任务的输入合同、任务模式、参考状态和交付状态规则。构图、身份、空间、系列视觉和失败恢复分别由对应模块维护。

## 输入合同

按任务需要消费当前有效上游交付，不重新推导已经确认的结论：

- 剧本分析：人物关系、冲突、题材承诺和不可剧透边界。
- 故事编写：当前场景的可见事件、动作因果和情绪转折。
- 资产：人物身份与时期造型、场景布局、道具数量、参考等级和确认状态。
- 视频提示词：时段、段首／段尾状态、可见与排除对象、动作阶段和连续性限制。

概念探索可使用最少必要输入；忠实还原具体剧情时必须读取直接相关的当前交付。缺少会实质改变身份、剧情瞬间、画幅、主体或文字的必要信息时，只确认最关键的一项；目标明确时直接执行。

## 任务定义

生成前确定：

1. 用途：主海报、角色海报、单集封面、剧情关键帧、场景参考、人物参考或编辑修复。
2. 画幅与文字：比例、唯一文案、排版安全区、后期文字计划和禁止出现的文字。
3. 输入图职责：身份、造型、场景、构图／风格或编辑目标，以及每项职责的权威等级。
4. 剧情瞬间：当前画面能让观众看出刚发生什么、正在发生什么和下一秒可能发生什么。
5. 不可变项：人物数量、身份、时期、形态、伤势、服装、场景、道具、时段和已确认布局。

## 新建与编辑

- 图片只用于身份、造型、场景、风格或构图指导时，按带参考的新建处理；人物参考默认不是编辑底图。
- 要求保留现有图大部分内容并局部修改时，按编辑处理；每轮列出保持不变的主体、身份、构图、道具、文字和光线。
- 编辑目标已经身份漂移时，同时使用更高等级身份参考并声明其优先；不得让漂移成图反向覆盖人物权威。
- 一套宣传图每张独立生成，统一身份和系列视觉语法，但每张承担不同传播主题。

## 参考绑定状态

- `待绑定模板`：可保留 `@image<编号>` 等模板位，但必须明确不可直接提交。
- `文字生成模式`：无参考的临时人物、临时场景或导演允许的概念探索，可使用已确认文字描述；不得把文字结果自动升级为固定资产。
- `正式绑定模式`：所有引用替换为真实输入映射；不得残留模板占位。

固定人物和跨图复用资产优先正式绑定。无参考不阻断概念探索，但正式交付必须说明采用的绑定状态。

## 保存与状态更新

- 原始输入和唯一原图保持不变；候选、修复版和成品使用不同文件名非破坏性保存。
- 输出记录用途、版本、输入职责、实际提示词、禁止项、检查结果和保存路径。
- 候选图默认仍是候选。只有导演明确确认后，才将其登记为人物、造型、场景、构图或风格参考，并更新 `00-当前状态.md`。
