# 图片生成失败恢复

本文件只在已有图片出现可观察缺陷，或导演明确要求准备修复方案时读取。它不参与首次构图，不按预期风险生成保守替代图。

## 触发与诊断

- 记录目标图片、预期画面、实际缺陷和可观察证据。缺陷可以是身份漂移、人物或道具复制、错误文字、穿模、接触失败、遮挡错误、区域错位、镜面错误、光线破坏空间或编辑范围外变化。
- 将主要缺陷归到身份、空间、动作／接触、文字、光线、构图或编辑保持范围中的一个；一轮只修改一个主要变量。
- 保留原方案和已通过的身份、剧情事件、构图、道具、文字或光线。修复指令明确列出本轮允许变化和必须保持不变的内容。

## 修复顺序

1. 补强缺失的权威参考、输入职责、区域、路径、遮挡、接触点或文字边界。
2. 仍失败时，只降低一个非核心复杂变量，例如减少无关背景动作、缩短约束物路径、降低不必要遮挡或把非核心精确文字交给后期。
3. 每轮生成后重新检查全部关键项，不能因为主要缺陷消失而接受新出现的变脸、复制、穿模、错字或剧情错误。
4. 达到导演要求的可用结果、确认工具能力边界，或继续修改将改变核心剧情／构图时停止并报告。

## 失败升级

- 修复图未通过全量关键项验收时留在图像恢复阶段，不返回视频恢复；有新的可观察证据时继续下一轮单变量修复，没有证据明确的下一变量时停止。
- 当前最后有效帧本身不适合修复时，回到视频恢复提供的候选帧集合，选择另一个身份、空间、动作阶段与承接均合格的候选；候选变更须重新经导演确认。
- 所有候选均失败或工具能力边界已确认时，关闭本次定点改图分支并把“无合格续段首帧”返回视频恢复。视频恢复随后只能提出整段重生成或更换工具，不得把同一失败帧再次路由回来形成循环。
- 整段重生成、更换付费工具或扩大外部生成次数属于新方案／新成本，由导演决定；图像阶段报告失败证据、已试变量、引入的新缺陷和停止依据。

## 最后有效帧定点改图

- 视频前段合格且从明确时间点开始出现局部失败、导演要求保留合格片段，并由视频恢复流程确认可用最后有效帧时，允许把该帧作为本次编辑目标。第一帧即错误、整体表演／运镜／剧情方向不合格或没有可自然承接的正确帧时不使用。
- 原始抽帧非破坏性保留；只在副本上编辑。优先使用人物身份、服装、场景、道具、光影、位置、朝向、视线、接触和动作阶段均正确，且无严重运动模糊、遮挡、面部或手部错误的“动作阶段清楚的稳定帧”。多个候选由视频恢复流程列明时间点、优缺点和推荐项，导演确认后再编辑。
- 每轮只设一个主要修改目标，明确全部保持不变项；修复图只建立下一动作可继续的起始状态，不提前完成后续动作。先建立 `<集数或片段>-<最后有效帧时间点>-定点修复提示词.txt`，记录错误、原帧职责、唯一修改、保持项、目标状态、禁止项、验收和续段用途，再询问由当前图像能力改图或由导演到其他平台制作。
- 修复图验收并经导演确认后才能返回视频恢复流程作为续段首帧；它不自动升级为人物、场景或构图权威。原始抽帧、修复候选和确认图分别保存，不互相覆盖。

## 多候选

导演要求多个候选时，说明候选之间的叙事或构图差异；不得把复杂方案自动标为较差方案。系列图片仍逐张独立生成和验收，不用上一张漂移成图替代身份权威。

## 交付记录

列出原方案、实际缺陷、本轮唯一改动、保持不变项、复核结果和停止原因。修复结果仍是候选，只有导演确认后才能升级为项目资产。
