# 交付检查

正式单集提示词先形成候选稿，再按本文件完成审核、修正和全量回归复审；末尾必须先显示“执行与依据清单”，再显示完整检查报告。业务规则正文只在所属模块维护，本文件唯一负责审核协议、检查映射和结果状态。

## 状态

- 通过：已经实际检查，并列出可定位到原文、生成段、镜头、资产或规则模块的证据。
- 警告：仍可执行；展开原因、影响和建议。
- 失败：违反硬约束；先修正。无法修正时说明阻碍，不标为可用。

任何状态都必须在完成检查后填写。模板不预填“通过”；未检查写“失败：未执行”，不得凭正文看似完整而推定通过。

## 五层审核门

按顺序执行，前层失败先修正再进入下一层；每层仍须登记已经发现的全部缺陷：

1. **G0 原文与授权**：检查1–4、19，确认推文正文范围、EP／场景边界、原文、前后文、信息边界、黄色旁白使用状态及旁白／对白分类。
2. **G1 覆盖与时间**：检查3、6–9、18、21，确认未标黄语义单元逐句画面覆盖、旁白保留片段、对白替换位、角色对白单独生成、对白避让、镜长、分段和时长核算。
3. **G2 表演与镜头**：检查12–16、22–25、39，确认表演、动作、空间、轴线、光影、承接及导演决策。
4. **G3 资产与提交**：检查5、10–11、17、20、26–38，确认参考、资产、工具字段、自包含结构、负向及文字边界。
5. **G4 结果恢复**：检查40；只有存在可观察生成失败或导演明确要求修复时执行，否则记“不适用”。

G0至G3均通过后候选提示词才具备交付资格；G4不参与首次设计资格判定。

## 审核证据与账本

- **原文覆盖矩阵**：`原文定位｜旁白／对白｜生成段｜镜头｜时长｜覆盖状态`，逐句证明无遗漏、错分、重复或错误归属。
- **连续性状态账本**：逐生成段记录末镜的人物位置、姿态、视线、方向、持物、动作阶段、构图重心与声音锚点，并登记下一段首镜实际兑现位置。
- **缺陷账本**：`PR-编号｜审核门／检查项｜失败／警告／建议｜定位｜依据｜问题｜影响｜修正目标｜状态｜回归项`。不得用总分、平均分或其他检查项的通过抵消失败。
- 检查项写“通过”时至少给出一个足以复核的定位证据；同一证据可以支持多个相邻检查项，但不得只写笼统结论。
- 警告分为执行性与授权性：等价机位、动作路径、蒙太奇顺序、镜长、构图锚点等可逆执行选择，由执行者按“原文与信息顺序 → 已确认资产 → 故事动力 → 画面表现力 → 动作与空间连续性 → 剪辑价值 → 工具边界 → 文本简洁度”选定并关闭；可能改变剧情、身份、能力、关键身体拓扑、信息揭示或导演明确偏好的授权性警告才暂停。

## 修正与全量复审

1. 锁定候选提示词版本，完成五层审核门及三份账本；审核遍历中只登记问题，不边查边静默改稿。
2. 按缺陷账本自动定点修正，每次关闭缺陷时登记实际改动及受影响检查项。修复优先级为“删除无依据新增 → 补足已确认状态 → 拆动作阶段 → 拆生成段 → 重建时期资产引用 → 重组蒙太奇 → 最后才改变原有镜头构思”，不以预期生成风险删除核心画面。
3. 修正完成后重新执行G0至G3全部检查及当前适用的G4，不得只复查修改镜头；同时重建原文覆盖矩阵和受影响的连续性状态。
4. 持续执行“候选稿 → 全量审核 → 登记全部缺陷 → 自动定点修正 → 全量复审”，不设固定轮次。零失败、执行性警告已自动关闭且授权性警告均有处理结论时为“可交付”；否则为“不可交付”。
5. 审核报告必须写明候选版本和复审所依据的实际文件。报告与候选版本不匹配时直接失败；只有可交付版本才能升级为当前有效提示词。

## 必须展开的状态

- 各权威模块中的“必须／不得／只允许／禁止”均为硬约束；除本节明确规定为警告的情况外，违反即标为失败并先修正。模板和检查表不降低模块约束。
- 正式旁白音频未到位：第7项写“警告：暂估”，不得声称已锁时。
- 推文项目未登记正文范围、EP／场景边界或黄色段使用状态：第1项标为失败；不得从图片、链接、评论区、颜色猜测或对话记忆补回剧情事实。
- 旁白音频含人物对白朗读但未登记对白替换位，或成片沿用该朗读作为角色声音：第8项标为失败；必须改由角色对白单独生成并复核旁白与对白不重叠。
- 有对白的主要重复人物缺少已确认参考音频、存在冲突映射或无依据换音频：第27或28项标为失败；不得用文字音色补位。
- 正式视频提示词与剪辑执行阶段全片平均镜长不在2.5–3.5秒、任一非高潮镜头超过4秒、5–6秒高潮镜头每集超过1处，长旁白／长对白跨越多个视觉节点却由同一主体同一景别同一构图停滞承载，或旁白持续段使用纯静止背景：第21项标为失败并先修正；故事画面阶段不因尚未锁定秒数而失败，也不得用长镜头自审掩盖同配置停滞。
- 未执行逐镜四层审查、只核对镜头数量与时间，任一镜头在语言、动作或信息承载量中仍有超载，或画面表现力仍然不足：第21项标为失败；必须重设镜长、景别、机位、调度、运镜、构图层次或剪辑落点并重新执行四层复核。不得以“单镜未超过4秒”降级为通过。
- 镜头标题未显示段内累计起止范围、仍保留镜头编号或“时长”字样，或时间范围存在空档／重叠、末尾不等于生成段总时长：第5项标为失败并修正。
- 项目画幅未确认：第24项写“警告：待确认”，不得自行套用画幅。
- 当前故事稿含故事动力传递摘要而提示词漏读、遗漏节点、静默改变场景目标／阻碍、对白行动／潜台词、关系权力、决定性动作／不可逆节点、视觉母题、结束状态或情绪方向／强度，且无法给出新的原文／导演确认依据时，第6、25或39项标为失败并按故事摘要重新设计表演、调度和切镜落点。
- 情绪动作存在多解而未锁定关系方向，情绪转折缺少触发／中间判断，或把克制抽离演成怨恨、把认清差距演成恶意时，第6、25或39项标为失败；先补正向情绪底色、触发事实和可见动作，再全量复审。
- 画面处于远景、失焦、背向或遮挡状态却仍要求观众读取细腻面部表演，或运镜未按“前置动作完成 → 启动 → 揭示 → 停止”执行时，第12、15或16项标为失败；改用可见体态／空间锚点或调整构图，并复核落幅与下一镜承接。
- 故事段直接等同生成段而造成时期、地点、造型或资产污染，高风险角色缺少必要身体拓扑，身体组成／肢体数量／连接来源跨镜矛盾，连续结构无法追踪来源／接触／施力／结果，普通时间跳跃被写成无依据连续变形，无依据机制改变剧情或因果，越过原文结束状态继续发展，蒙太奇组合后没有递进／对照／回收／状态变化，或关键硬切没有落幅—起幅接力时，对应第2、3、9、10、13、16、19或21项标为失败并自动修正。
- 蒙太奇尚无实际素材或粗剪时，只能报告蓝图与提示词状态；素材和粗剪写“待生成后审核”。预填尚未观察的素材／粗剪为通过，按第9项失败。

- 相邻、当前场景或整集任一层存在无戏剧任务的轻微切镜、连续面部近景／特写滥用、空间失效、特写强度透支或可用环境／肢体／道具／关系叙事长期闲置时，第16项标为失败。直接采用最有表现力且不违反原文、时长、动作、连续性、轴线与资产规则的方案持续修正并重新审核，直至三层与回归检查全部通过；最终在提示词区外只列实际发现并已修复的问题及方案。

- 没有可观察生成失败且导演未要求修复方案时，第40项写“不适用”；若首次选镜阶段按预期风险加载失败修复、建立稳定性评级或预先降低画面复杂度，第40项标为失败并回到首次创作规则。
