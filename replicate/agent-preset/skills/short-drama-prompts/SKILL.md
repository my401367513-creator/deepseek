# 短剧技能：提示词生成（Seedance 2.0 Prompts）

流水线第三环：**分镜表 + 资产库 + canonical 描述词 → 逐镜可执行提示词**。
默认工具：Seedance 2.0（即梦）。用户点名其他工具（可灵、Runway、Sora、海螺、Vidu、Pika 等）时按该工具语法适配。

## 1. 能力背景

Seedance 2.0 支持文生视频、图生视频、首尾帧、多镜头叙事、镜头运动控制、人物一致性（参考图/首帧）。竖屏短剧默认 9:16——**画幅在即梦参数面板设置，不写进提示词**。

## 2. 统一结构（当前规范）

```
[全局词头：风格/质感/景深/布光 + 项目级全局要求（如无BGM）+ 负向提示]
[资产引用段：人物：/ 场景：/ 道具：/ 音频：]
[镜头：景别与构图 + 主体与动作 + 镜头运动 + 光线与色调 + 时长]
```

- **全局词头**：全片不变的风格/质感/景深/布光条件 + 项目级全局要求（如「无背景音乐，仅环境音/音效/配音」）写在同一段，**每条提示词开头必带，镜内不重复**。模板：`电影感写实，胶片颗粒，浅景深，真实质感，电影级布光，细节丰富。无背景音乐。严格按原剧情执行，不增删情节不改台词。` 换风格（国风/动漫/赛博）时整体替换词头，镜头段结构不动。
- **剧情约束（用户要求，必带）**：词头必须声明「严格按原剧情执行，不增删情节不改台词」——生成内容忠实于剧情与分镜，不擅自添加/删改情节、台词、设定；所有内容围绕剧情展开。
- **负向入词头（全局约束）**：多次出现的负向提示统一放进词头，**逐镜不重复**。默认：`负向：变形、多指/六指、面部崩坏、文字乱码、屏幕字体变形、画面闪烁、抽帧、多余肢体、前后镜头不一致、眼珠变形`（可按项目增删）。
- **资产引用段**：本镜涉及的资产前置声明，按类型逐行（**只列本镜涉及的类型**，无则不写）：
  - `人物：<姓名>，<canonical 描述词>`（来自 characters.md，去尾部风格词）
  - `场景：<资产名>，<固定描述词>`（来自 assets.md）
  - `道具：<资产名>，<固定描述词>`
  - `音频：<资产名>，<声音要点>`（BGM 等全局音频在词头/稿头声明，不逐镜重复）
- **镜头段**：景别 + 具体动作（动词具体，拒绝「很悲伤」这类抽象词）+ 运镜（推 push in / 拉 pull out / 摇 pan / 移 track / 跟 follow / 环绕 orbit / 手持 handheld / 甩镜 whip pan；慢动作/变速）+ 光线色调（具体光源与情绪）+ 时长。**不再重复全局负向**。
- **参数**：时长、参考图/首帧。画幅不写。

### 2.6 Seedance 2.5 时间轴分镜模式（用户示例学习）

即梦 Seedance 2.5 支持多镜头时间轴生成（单条最长 15s，可连续多镜）。**只学习其提示词格式；默认无 BGM，除非用户脚本明确要求 BGM**：
- **头部五段声明**：风格（含光影/节奏约束，如「午后阳光斜照，暖光里带冷；镜头稳定不快闪」）→ 场景（固定描述词）→ 人物（`姓名@资产图（锁脸）`，即梦参考图引用语法）→ 约束（如「无字幕/文字」「无旁白朗读」）→ 音频（SFX 明细；默认无 BGM，仅环境音/音效/配音）
- **时间轴分镜**：每条提示词标注镜段时间轴（如 0.0–2.4s），镜头段 = 景别 + 画面 + 运镜 + 光线 + 时长；旁白/台词独立成行（后期配音），**不写进生成提示词**
- **无字幕约束**：词头声明「无字幕无文字」+ 负向追加「字幕、文字」
- **定格收尾**：末镜可写「最后 0.4 秒画面定格不动」便于剪辑截取
- 每条提示词仍遵守一镜一画面纪律

### 2.7 镜头参数规范（摄影语言，镜头行必带）

镜头行格式：`<时间轴> <景别> <机位/角度>，<焦距> f/<光圈> [景深]，<画面细节描述>。`

**焦距词典**：
- 24–35mm 广角：强化空间纵深与冲击（刹车急停、全景揭示、环境压迫）
- 50mm 标准：叙事视角，中景/近景主力
- 85–135mm 长焦：压缩空间、情绪聚焦（车窗升起、瞳孔、屏幕特写）
- 100mm 微距：细节放大（磕地、手部、道具质感）

**光圈与景深**：
- f/1.8–f/2.0：大光圈浅景深，背景虚化，情绪特写（大特写/金句镜）
- f/2.8：常规叙事景深，兼顾环境（中近景主力）
- f/4 及以上：深景深，环境交代（全景、时间跳跃揭示）

**机位与角度**：
- 低机位贴地：卑微/冲击（跪地、轮胎溅雪）
- 仰拍 15°–30°：压迫/癫狂（嘶吼、上位者气场）
- 俯拍：支配/审视（手机、跪姿、蜷缩）
- 肩平：客观叙事；侧面：情绪观察（瘫跪、呆望）

**示例镜头行**：
```text
0.0–5.0s 中近景车内固定微推，50mm定焦 f/2.8，塞莉娜侧脸望向窗外，全程不转头，车内暖橙vs窗外冷蓝双色调。
```

### 2.8 定位关系（词头/资产段必带）

资产引用段加入 **`定位：`** 行，声明本段空间布局，保证多人/多物同框构图稳定：
- **定位资产图**：多人/多物同框场景，建议提供或生成一张站位定位图，用 `@定位资产图（人物站位参考）` 引用（锁位）
- **文字参考图（ASCII 构图图 + 垂直剖面，用户规范）**：无资产图时用 ASCII 框线图画出画面构图——**竖框代表 9:16 画面边界**，框内标注元素方位（前景/中景/背景、左/右/中），用 `→` 标光源方向。**ASCII 图只表达平面（左右/前后），必须追加「垂直剖面」行表达上下/高度关系**：列出各元素高度（m）、机位高度与视线方向（谁高谁低、仰/俯/平视）。元素用 `[名称]` 或简写标注。
- 镜头行内各镜的具体站位变化继续保留（如「他身后是轿车车头」）

**示例定位行（ASCII 构图图 + 垂直剖面）**：
```text
定位：
┌─────────────────────────┐
│  背景：黑松林·大雪         │
│        ┌──────┐         │
│        │幻影轿车│(右·中景) │
│        └──────┘         │
│         车灯→(右→左)     │
│  [亚历克斯](左·前景·跪)    │
└─────────────────────────┘
垂直剖面：轿车(≈1.6m) > 车灯(≈1.2m) > 亚历克斯跪姿(≈0.9m) > 雪地(0m)；镜头贴地低机位仰视
主光：车灯（右→左）· 冷蓝夜色· 间距约五米
```

### 2.9 描写风格双模式（每次生成前询问）

用户保留两种镜头描写习惯，**每次生成提示词前必须用 ask_user_question 询问选择哪种**：

- **风格 A · 文学细腻**：允许成语、意象化修辞与氛围渲染（如「青筋暴起」「一片死寂」「气场压人」），强调情绪质感与画面意境。
- **风格 B · 直白拆解**：平实直白，动作/表情拆解到肢体细节（如「喉咙血管鼓起来」「手指陷进雪泥」「呼吸明显变得急促」），不用成语和文学化修辞。
- 两种风格**只影响镜头行的动作/表情措辞**；词头、资产引用段、定位图、镜头参数、台词内嵌、剧情约束等结构完全一致。

## 3. 一镜一画面纪律（关键）

**一条提示词 = 一个镜头**：单一机位 + 单一主体/动作组。以下情况必须拆成独立镜头：
- 动作与反应（如「轿车驶过溅泥」与「男子呆跪望车尾」）
- 不同机位的画面（如「手拉手刹」与「轮胎急停溅雪」）
- 单条提示词内禁止写「硬切」「转场到」等剪辑指令

## 4. 一致性技巧

- **角色**：复用 `characters.md` 的 canonical 描述词（30–60 字）；关键镜头用参考图/首帧锁定形象
- **资产**：复用 `assets.md` 的固定命名引用（如 `资产:幻影轿车内`）
- **连续动作**：多镜头连续动作时说明上一镜头结束状态（「承接上镜，她从门口转身」）

## 5. 负向提示（常见）

变形、多指/六指、面部崩坏、文字乱码、画面闪烁、抽帧、多余肢体、前后镜头不一致、眼珠变形。

## 6. 模板示例与可替换参数

```text
电影感写实，胶片颗粒，浅景深，真实质感，电影级布光，细节丰富。无背景音乐。严格按原剧情执行，不增删情节不改台词。
负向：变形、多指/六指、面部崩坏、文字乱码、屏幕字体变形、画面闪烁、抽帧、多余肢体、前后镜头不一致、眼珠变形。
人物：女主角，<canonical 描述词>。
场景：老城区黄昏街道，潮湿青石板，墙上斑驳海报。
音频：巷口市声，环境底噪。
镜头：中景手持跟随，从巷口疾步走来，攥紧信封，轻微晃动慢动作，黄昏逆光暖橙色调。时长10s。
```

每段提示词后附一行「可替换参数」说明（时长/景别/运镜可替换为其他值）。

## 7. 记忆库读写（本技能负责）

- **记忆根解析**（每次会话检查一次）：环境变量 `SHORT_DRAMA_MEMORY` 非空且路径存在 → 用之；否则默认 `{{cwd}}/short-drama-memory/`。云端同步与复刻协议见记忆根内 `REPLICATE.md`。
- **会话开始**：先读 `MEMORY.md` 恢复上下文；能判断项目时再读 `projects/<项目名>.md` 与 `prompt-templates.md`。
- **本技能负责写入**：`prompt-templates.md`（产出或打磨提示词后去重沉淀最有效写法）；`lessons.md`（交付后追加「什么有效/什么无效/用户纠正」）。
- **用户纠正**：立即记入 `lessons.md` 与 `MEMORY.md` 偏好区，并在后续输出中遵守。
- **纪律**：只记录事实与用户确认的偏好，绝不编造；文件不存在用 `write` 创建，存在用 `edit` 增量更新。
