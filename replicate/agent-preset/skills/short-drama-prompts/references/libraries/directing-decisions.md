# 导演决策方法库

本库用于首次镜头构思和镜头语言诊断，负责把剧情任务转化为可读的观察关系、注意力路线和摄影机行为。它不改变原文、时长、轴线、硬切、资产或输出规则，也不按模型风险降低首次构思。普通单主体或已有明确镜头方案时不必加载。

正式单集或复杂节点有导演叙事桥接卡时，先消费中心技能的 [导演叙事判断总纲](../../../short-drama-director/references/narrative-directing-principles.md)：事件、冲突、反应波动、空间张力、细节功能和事实／知情边界是已锁定输入；演绎与观众空间只用于选择不改变事实和关系结果的表达方案。本库负责把这些输入转译为主导任务、观看目标、主体、景别、构图和运镜，不重新猜测剧情。

## 主导叙事任务

- 镜头选择从“观众此刻必须先读懂什么”开始，不从景别、机位、越肩或某种运镜开始。先根据当前原文节点、故事动力、人物知情状态和信息边界，确定一个主导叙事任务：情绪、动作、关系、悬念或信息揭示。
- 每个节点最多再指定一个辅助任务。主导任务获得清晰度、视觉重心和主要摄影机资源；辅助任务只能通过次级构图、声音、局部动作、空间关系或景深支持，不得与主导任务争夺视觉中心。
- 五类任务不设固定全局优先级，按当前节点的不可逆变化、误读风险、必须看清的事实和后续信息边界动态选择。若任务冲突，优先保证主导任务可辨，再保留辅助任务所需的最低证据。
- 任务确定后，先把主导任务转译为“观众此刻必须先读懂的可见变化”，再依次选择主体、景别、机位、构图、遮挡、焦点和运镜；选择结果必须能说明它如何让主导任务比其他合规方案更清楚。抽象的“压迫感”“悬念感”等只留在制作参考，不直接代替提示词中的可见动作与摄影执行。

五类主导任务的最低读法：

- **情绪**：先让观众读懂人物内在变化或情绪转折，使用面部、体态、呼吸、手部或主观感知的可见证据。
- **动作**：先让观众读懂力量、接触、方向、动作阶段或结果，使用受力链、空间路径、接触点和落幅。
- **关系**：先让观众读懂距离、控制权、观察关系或关系边界，使用双人几何、位置差、视线轴、遮挡和空间移动。
- **悬念**：先让观众读懂被隐藏的对象、危险来源或搜索方向，使用留白、局部、反射、离画来源、受限视线和信息延迟。
- **信息**：先让观众读懂谁知道什么、何时揭示什么或哪个证据改变理解，使用视线引导、道具揭示、摄影机揭示路径和构图重心。

交付制作参考应记录“主导任务｜辅助任务（无则写无）｜选择依据”。可提交提示词只保留由任务选择产生的画面指令，不写抽象决策过程。

## 第一镜追看任务

- 短剧第一镜不能仅说明地点。先判断它能否在不泄露后文的前提下，同时完成核心人物或危险、独特世界规则、强空间／动作关系、立即产生的问题或识别性视觉母题中的至少两项。
- 高危人物入场可从“对象进入画面 → 专业人员如何响应 → 摄影机揭示更大制度空间”组织注意力，但不把它固化为题材公式；人物、制度反应与空间揭示必须服从原文事实和项目参考。
- 第一镜的冲击不能来自尚未发生的攻击、后文伤势、未揭示道具功能、关系答案或未经支持的群体态度。导演确认正式开场后，以项目状态为准，不在局部修订时擅自替换候选方案。

## 双人对白与过肩组合

- 先确认关系距离、控制权、当前说话者、关键倾听反应和必须看清的动作，再选择双人关系镜头、过肩、干净近景、特写或画外连续对白；说话人切换不自动取得切镜资格。
- 使用过肩时写清前景人物、肩部或后脑所在画面侧、清晰主体、视线方向和口型归属。反向过肩继承人物左右、轴线侧别、距离、姿态和动作阶段。
- 前景只建立关系和纵深，不遮挡当前主体的脸、口型、关键手势或道具。连续反打若只交换肩位而没有新增信息、独立反应、动作或关系变化，应合并或改换观察方式。

## 近景与特写的戏剧强度

- 把近景与特写视为有限的戏剧强度资源。先确定当前节点是否需要观众读脸；隐秘心理、心理压迫、博弈状态变化、局部情绪高潮、单镜情绪流转、抽离麻木或项目明确的纪实表达可以主动弱化环境，普通信息传递不默认收紧景别。
- 选择面部景别时明确进入理由和退出时机。高潮前保留可收紧的景别距离，高潮后通过关系、动作、环境或空间释放强度；不得让全片长期停留在相同面部尺度，使关键特写失去冲击。
- 单人段落优先沿剧情因果寻找变化：视线目标，其次是关键道具、身体动作与结果，再到人物和环境／空间压力的关系，最后才使用既有背景活动。这里是观察资源，不是固定轮换表；最佳画面仍由当前戏剧任务决定。
- 多种合规方案并存时，依次保护原剧情与信息顺序、戏剧重点、画面表现力、空间／动作／视线／道具连续性、后续高潮的升级空间、工具时长与生成段边界，最后才考虑文字简洁。

## 运镜决策

- 先判断固定机位是否已经能让表演、画内调度或动作结果成立，再判断运镜需要改变哪一种观看关系。运镜不必每次揭示新事实，但必须改变心理距离、注意力归属、空间／关系、动作可读性或感知状态中的至少一项；人物表演和画内调度已经足够时，固定机位是主动选择。
- 按表达层级选择运镜：0级静态观察，依靠表演、调度或结果落点完成变化；1级轻微收紧／释放，允许在有可见呼吸、姿态或视线递进的情绪段落中改变心理距离；2级关系／信息运动，通过侧移、跟拍、环绕、穿障或焦点交接改变空间关系、注意力归属或信息次序；3级主观／失控运动，通过手持、甩镜、急推急拉或偏轴运动表现正文支持的震惊、慌乱、失衡或追逐。运镜层级不是强度排名，而是对当前主导任务的表达选择。
- 每次运镜建立一条完整决策链：注意力起点 → 可见或可听触发 → 启动方式 → 方向、物理路径与速度变化 → 沿途信息与遮挡／视差变化 → 叙事目标 → 减速收势或有依据的骤停 → 稳定落幅。启动理由和停止理由同等重要。
- 一个镜头可以有多阶段运动，但须服务同一主要叙事任务并保持一个视觉主导中心。不得用无终点的持续慢推、来回扫动或任意变速填满镜长。

## 注意力与相对运动

- 运镜开始前确定观众注意力从何处出发、最终交给谁或什么。原主体失去视觉主导前，用视线、声音、动作、道具、景深或构图重心完成交接；一次主要运动只完成一次主要注意力交接。
- 摄影机与主体可采用提前引导、同步跟随或主体先动后短暂迟滞追随。选择依据是行动目标、突发性、观察立场和信息边界，不把主体始终居中或完全同步当成默认。
- 先确定主运动与响应运动。人物承担复杂动作时，摄影机运动须让动作阶段可读；摄影机承担复杂揭示或关系重构时，人物与背景变化须形成主次。高复杂度可以保留，但人物、摄影机和背景不能成为三个竞争的视觉中心。
- 视觉运动负荷综合摄影机位移、角度、焦距与景别变化、主体画面位移、前景视差、手持幅度、背景动态和镜长判断；不是只看摄影机速度。负荷过高时重新组织主次或拆分叙事任务，不因模型风险预先降级。

## 观看目标与主体标注

- 提示词设计顺序固定为：观看目标（观众此刻必须先读懂的可见变化） → 画面主体与动作／反应 → 景别、机位、构图、焦点与运镜 → 当前镜头需要执行的连续性约束。可提交提示词只保留后三层的可执行画面指令；制作参考另记录主导任务、辅助任务和观看目标。
- 只有当做动作的人与承受情绪、掌握信息或改变关系的人不是同一人时，才强制区分“动作主体”和“情绪／信息主体”；同一人物承担两种功能时合并描述，避免为单人镜头制造空泛双主体字段。

## 段界与诊断

- 生成段边界优先落在已经完成的叙事结果、观察主体交接、动作阶段完成、声音落点、认知变化或原文明示的时空转换处；不为制造切口强行增加特写、换人或换场。
- 诊断镜头时依次检查：主要叙事任务、视觉主导中心、注意力起点与交接、运镜触发与落点、人物和摄影机的主次、对白观察关系、核心信息可读性、段界叙事落点。
- 这些方法提供候选和诊断依据，不建立“某情绪必用某镜头”的公式，也不把外部案例的片名、剧情或未经验证的比例转化为通用规则。
