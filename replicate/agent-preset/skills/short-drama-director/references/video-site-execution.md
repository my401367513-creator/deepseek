# 视频生成网站执行

仅在导演要求 Codex 操作指定视频生成网站时读取。使用可用的浏览器控制技能操作导演指定或当前项目登记的网站；登录、验证码、付款或人工安全验证交由导演完成。

## 输入门

开始前从 `00-当前状态.md` 重新读取并锁定：

- 审核通过的当前视频提示词，以及每个生成段的唯一编号；
- 已确认资产库及资产文件、站内资产名或站内资产 ID；
- 项目确认的视频工具、模型、画幅、时长、清晰度、音频与其他生成参数；
- 本批范围、提交授权、最大任务数或额度边界。

任一生成段存在未确认资产、提示词仍是候选稿、参数无唯一取值，或本地资产无法对应到网站中的唯一对象时，停在该段并列出缺口。不得按缩略图相似度、列表顺序或名称猜测资产。

## 网站档案

首次使用某网站或页面结构变化时，先只读检查页面，建立或更新当前项目内的网站档案；通用技能仓库不保存账号、项目素材或机器专属信息。档案至少记录：

- 网站入口与适用页面；
- 提示词输入区、资产选择区、模型与参数控件、提交控件的可复核标签；
- 站内资产标识与本地资产 ID 的映射；
- 单任务资产数量、提示词长度、时长和并发限制；
- 提交成功的可观察证据，以及任务 ID、状态和结果入口的读取位置。

页面控件与档案不一致时，以当前页面可见状态为证据，暂停会产生费用的动作并向导演报告差异；确认后再更新档案。

## 提交清单

按生成段建立一行提交清单：`生成段 ID → 提示词版本 → 资产 ID/站内对象 → 模型与参数 → 目标任务数 → 授权状态 → 网站任务 ID → 当前状态`。逐段执行，不把多个段落混入同一任务。

每个生成段按以下闭环处理：

1. 打开正确的生成页面并确认账号、工作区或项目。
2. 选择模型与参数，绑定提交清单中的唯一资产。
3. 原样填写“可直接提交的视频提示词”区域；制作参考、审核说明、占位符和未启用资产不进入网站。
4. 回读页面中的提示词、资产和参数，与提交清单逐项一致后，把该段标为“已填写待提交”。
5. 若本批只有填写授权，在提交前停止并向导演展示待提交数量与关键参数。若已有当前批次的明确提交授权，点击一次提交并等待可观察结果。
6. 只有页面出现成功提示、任务卡或任务 ID 才登记“已提交”；超时或结果不明时登记“提交状态不明”，先查询页面任务列表，禁止重复点击。

## 授权与停止条件

- 导演说“填写”“帮我填好”只授权操作到提交前；“生成”“提交这批”或同等明确表达才授权本批提交。
- 授权只覆盖已展示范围和数量。新增段、重试、变体、放大、续作或重新生成分别视为新的额度动作，除非导演已明确给出数量边界。
- 单段失败不阻断已授权且相互独立的后续段，但必须保留失败状态；登录失效、工作区不确定、额度不足、页面结构变化或连续两次同类交互失败时停止批量执行。
- 不删除站内资产、历史任务或成片；不修改账号、套餐、支付或公共发布设置。

## 完成标准

填写任务完成：本批每段均处于“已填写待提交”或有明确缺口，且页面回读与提交清单一致。

提交任务完成：本批每段均有唯一网站任务 ID 或明确失败／状态不明记录；向导演报告已提交、失败、状态不明和未处理数量，并把任务 ID 与结果入口保存在当前项目的执行记录中。生成中的任务只报告已提交，不声称视频已完成。

## 结果验收闭环

提交后的任务只有在结果可访问时才进入结果验收；“已提交”不等于“结果验收通过”。每个生成段建立一份绑定任务 ID、提示词版本、资产版本和结果文件的验收记录，至少保留以下可复核证据：

- **代表帧**：首帧、尾帧和每个主要动作／信息转折的时间点或抽帧；逐项核对人物身份、服装／身体拓扑、道具状态、视线、空间方向、遮挡和光线连续性。
- **时长与结构**：实际时长、生成段边界、硬切位置和上一段尾帧／本段首帧的承接；检查是否出现截断对白、跳动作、重复动作、漂移或未完成的动作落幅。
- **声音与口型**：记录对白、旁白、环境声和静音的实际轨道状态；核对对白归属、口型与声音归属、关键停顿／呼吸、音画同步和旁白避让。原设计无某类声音时记录“有意缺失”，不以缺失本身判错。
- **表演与叙事**：核对主导情绪、被压住的次级情绪、对白行动、无对白反应和决定性动作是否可见；确认原文覆盖、信息揭示顺序和场景结束状态没有被生成结果改写。

验收结果只使用“通过”“失败”“状态不明”。失败须登记可观察证据、影响时间点、缺陷类别和回流位置：身份／动作／声音／空间缺陷回到提示词生成恢复，硬切或节奏缺陷回到段落结构与剪辑承接；涉及剧情、资产身份或新增外部成本时暂停请导演确认。状态不明时先查询任务和结果入口，不凭缩略图或模型状态猜测通过。

只有所有生成段均有完整验收记录且为“通过”，才报告“结果验收通过”并更新项目状态；任一段失败或状态不明都保留原状态、结果证据和下一步，不得把“已提交”升级成成片完成。修复后的新结果必须重新执行上述全量验收，不能只检查本轮改动。
