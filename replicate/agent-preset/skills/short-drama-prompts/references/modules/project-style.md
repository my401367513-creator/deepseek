# 项目风格与光影边界模块

本模块是视觉媒介、画幅和项目级风格边界的唯一规则源。具体光型与色彩方案按需查 `libraries/lighting.md`。

## STY-01 项目视觉媒介

- 默认视觉媒介为真人写实。项目明确采用动画、插画、定格或其他非真人媒介时，以项目确认值覆盖默认。
- 地域、时代、题材、美术方向、服化、色彩、光影和镜头气质均由每个项目单独确定并记录，不默认套用“欧美”、暗黑轻奢、好莱坞、8K或其他示例风格词。
- “电影感”必须落实为可观察的摄影、光源、材质、调色、运动和表演要求，不用“无AI痕迹”“大师作品”等不可验证口号替代执行描述。

## STY-02 画幅

- 画幅由每个项目单独确定并写入当前项目记忆，不设16:9、9:16或其他全局默认值。画幅由工具参数面板控制时，不写入统一词头或逐镜提示。
- 尚未确认时标记“待确认”，不得自行套用。同一项目一经确认则跨集保持，除非导演明确修改。

## STY-03 真实光源与连续性

- 先确定可解释的实景光源，再选择风格。光源方向、色温、反差、阴影和人物受光侧在连续镜头中保持稳定。
- 灯光或色彩只有在时间、天气、开关灯、拉帘、开门、人物进入另一光区或移动实景光源等可见触发发生时才变化，并把结果交给下一镜继承。
- 人物肤色、服装固有色和关键道具颜色优先准确，不被调色吞没。连续对白优先保持面部曝光和口型可辨识。
