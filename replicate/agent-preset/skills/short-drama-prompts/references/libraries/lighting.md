# AI短剧光影与色彩库

本库用于建立物理光源、选择光型并核对跨镜稳定性；项目风格边界服从规则模块。

## 场景光影锁定字段

```text
时段与天气：<室内/室外，具体时段，天气>
实景光源：<窗、太阳、顶灯、台灯、路灯、屏幕等及其位置>
主光：<来源、画面方向、人物受光侧、硬/软、色温>
辅光：<来源、方向、强弱或与主光的反差关系>
轮廓/背景光：<有则写真实来源；无则写无>
阴影：<方向、边缘软硬、密度>
曝光：<正常、高调、低调；高光与暗部保留要求>
基础色彩：<主色、中性色、点缀色、肤色要求>
连续性锁定：<不可随镜改变的光源、方向、色温与影子>
允许变化：<剧情触发条件及变化后的状态>
```

## 稳定性

- 高：单一主光方向明确、色温关系简单，通常可直接生成。
- 中：混合色温、逆光、低照度或可见光束，需要减少人物、动作和背景复杂度。
- 低：灯光闪烁、快速明暗变化、多色动态霓虹、运动中连续换光；优先拆镜或后期完成。
- 人物肤色、服装固有色和关键道具颜色优先准确。连续对白优先稳定面部曝光。
- 连续对白不得让强逆光、频闪或动态彩光破坏口型、五官和人物身份稳定。

## 基础光型

| 光型 | 真实光源与用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 自然日光 | 窗外天空、太阳；日常、客观叙事 | 高 | 写清窗户与太阳方向，跨镜不跳边 |
| 阴天漫射光 | 云层大面积柔光；克制、现实 | 高 | 阴影柔和但不能完全无方向 |
| 金色时刻 | 低角度夕阳或晨光 | 中 | 时段必须成立，连续场景色温不漂移 |
| 蓝调时刻 | 日落后冷天光配室内暖灯 | 中 | 锁定冷外暖内关系，不逐镜互换 |
| 高调柔光 | 窗光、柔化灯、白墙反射 | 高 | 保留面部层次，不做无阴影塑料感 |
| 低调高反差 | 单侧窗、台灯或窄束灯 | 中 | 暗部仍需识别人脸和关键动作 |
| 伦勃朗式侧光 | 单侧较高主光；内敛张力 | 中 | 必须有对应窗或灯，不机械套用 |
| 顶光 | 吊灯、路灯、天井 | 中 | 防止眼窝全黑，必要时有合理弱辅光 |
| 底光 | 地灯、火焰、低位屏幕 | 中 | 仅有真实低位光源时使用，时长从短 |

## 逆光与体积光

| 光型 | 用途 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 逆光 | 入场、分离、身份暂不清晰 | 中 | 写明背后光源；需要看脸时补真实反射 |
| 剪影 | 暂时隐藏身份、强调动作轮廓 | 高 | 不用于口型、表情或身份识别镜头 |
| 轮廓光 | 人物与背景分离、夜景边缘 | 中 | 必须来自后方窗、灯或太阳 |
| 丁达尔／体积光 | 有雾、尘、水汽环境的可见光束 | 中 | 同时写明介质和窄束光源；普通无雾、无尘、无水汽的干净室内不得添加 |
| 门缝／窗缝光 | 揭示、窥视、空间阻隔 | 高 | 形状服从真实开口，位置跨镜一致 |

## 实景光与混合色温

| 方案 | 真实来源 | 稳定性 | 执行限制 |
|---|---|---:|---|
| 暖色台灯／吊灯 | 钨丝灯、暖色LED | 高 | 暖光范围与灯具位置一致 |
| 冷色办公顶灯 | 荧光灯、冷色LED | 高 | 避免无依据频闪，保留肤色 |
| 屏幕光 | 手机、电脑、电视 | 中 | 只影响靠近屏幕的区域，亮度不过曝 |
| 路灯与车灯 | 夜间道路真实灯具 | 中 | 明确方向和车辆路径 |
| 冷外暖内 | 夜景或阴天冷光加室内暖灯 | 中 | 固定空间关系，不逐镜翻转 |
| 暖外冷内 | 夕阳或街灯加室内冷灯 | 中 | 符合时段和灯具类型 |
| 霓虹混合光 | 店招、街区霓虹 | 低 | 固定两种以内主色，禁止快速多色闪烁 |
| 烛火／火焰 | 可见火焰 | 中 | 轻微自然波动，不让人物脸持续变形 |

## 色彩方案

以下方案基于场景材质、服装和真实光源选择，不是固定情绪公式。

| 方案 | 适用条件 | 稳定性 | 限制 |
|---|---|---:|---|
| 中性自然色 | 日常、客观叙事、资产确认 | 高 | 默认方案，肤色真实 |
| 暖色主导 | 暖灯、夕阳或暖色空间存在 | 高 | 不把所有肤色染成橙色 |
| 冷色主导 | 阴天、夜景或冷色灯具存在 | 高 | 保留皮肤与关键道具识别度 |
| 青橙分离 | 冷背景与暖肤色同时成立 | 中 | 适度使用，不作默认电影滤镜 |
| 低饱和 | 原剧情明确的疲惫、现实或回忆 | 高 | 不改变服装和道具识别色 |
| 高饱和点色 | 关键物件或场景本身色彩鲜明 | 中 | 主色不超过两到三种 |
| 单色倾向 | 梦境、监控或明确风格段落 | 中 | 与常规现实段落有剧情边界 |

## 光线变化协议

连续场景只在以下条件变化：时间推进；天气变化；人物开关灯、拉帘、开门或移动屏幕；人物进入另一既有光区；车辆、路灯等移动实景光源经过。每次写明触发动作、开始点、受影响区域、新旧色温与方向，以及下一镜继承状态；没有触发则保持不变。

## 常见失败与修正

- 光源漂移：复述固定方位和人物受光侧。
- 无源轮廓光：增加可见合理光源或删除轮廓光。
- 肤色跳变：锁定肤色与白平衡，只改变景深和构图。
- 影子跳轴：锁定主光方向和机位轴线。
- 强光吞细节：降低反差或加入真实反射辅光。
- 动态彩光变形：固定两种以内颜色，或交给后期。
