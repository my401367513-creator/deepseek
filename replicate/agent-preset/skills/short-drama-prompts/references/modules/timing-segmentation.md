# 镜长与生成段模块

本模块是镜头时长、4–30秒生成段、核算和长镜头报告的唯一规则源。正式音频状态由 `audio-timeline.md` 提供。

## TIM-01 单镜时长

- 默认单镜不超过4秒，但不得机械生成等长镜头，也不为凑时长拉长静止画面。
- 4秒是默认上限，不是镜头无需拆分的充分条件；镜内动作、情绪或认知变化密度过高时，按表演模块的独立变化节点拆镜，即使原镜短于4秒。
- 只有对白、连续动作、反应递进或信息辨识确实无法在4秒内自然完成时才使用长镜头。
- 镜头定稿前分别检查语言与动作可完成性：对白须能按设定语气、停顿和口型自然说完；动作链须能在镜长内真实完成。
- 对白总时长不设上限；需要避免的是单一画面冗长，而不是强行截断对白。长对白按表演模块切为同期和画外连续对白。

## TIM-02 长镜头报告

- 所有超过4秒的镜头在交付末尾逐镜列出：镜头号、时长、对应原文、无法在4秒内自然完成的理由、可拆机位与自然切点、确认状态。
- 导演尚未确认时标记“待导演确认”，不得擅自视为最终保留。导演观看后决定保留或拆分。
- 已确认且内容未变化的长镜头继承确认状态，后续版本不重复询问；镜长、表演或内容发生实质变化时重新汇报。

## TIM-03 生成段边界

- 单次生成4–30秒。先设计镜头，再按完整叙事单元确定段界；场景、时段变化或镜头数量本身不自动触发拆段。
- 每个生成段最多8个镜头。镜头设计完成后再按叙事单元、对白归属和连续性选择段界；第9镜不得进入同一生成段。
- 超过8镜时优先移动段界并增加生成段，不得为压缩镜头数强行合并独立信息、动作阶段、情绪转折或认知节点，也不得延长单镜掩盖复杂度。调整后每段仍须满足4–30秒。
- 不把4–6秒短段作为默认方案。只有镜头上限、总时长、对白或动作完整性、连续性风险，或实测生成失败要求时进一步拆分。
- 分段只改变生成批次，不改变原文顺序、旁白／对白分类、剧情事实或信息边界。
- 同一段连续对白必须完整放在同一个生成段内，不得跨越两个生成段。该对白可在段内按自然语义停顿或动作触发硬切到说话者、倾听者、说话者动作或已有道具，并使用画外连续对白保持声音连续。
- 生成段边界不得落在词语、不可拆短语、连续对白或不可拆动作内部。先移动段界；若整段对白连同必要表演超过30秒，则保持对白原句与声音连续，在导演确认具体生成方案前不得擅自截断或改写。

## TIM-04 时间核算

- 每段时间轴从0.0秒开始，允许小数；镜头连续、无空档、无重叠，时长合计必须等于段长。
- 正式旁白音频未到位时只能标记“暂估，待正式音频锁定”；收到完整音频后按实测重建，不沿用旧估算冒充锁时。
- 分段完成后核对每句旁白、对白占位、同期对白和画外连续对白的承载范围，确保旁白与对白不重叠。
