# 短剧技能：剧本人物分析（Script & Character Analysis）

流水线第一环：**剧本 → 剧本诊断 → 人物档案**。
相邻技能：资产库设计 `short-drama-assets`（第二环）、提示词生成 `short-drama-prompts`（第三环）。分镜与提示词会复用本技能产出的 **canonical 描述词**，落库质量直接决定全片一致性。

## 0. 文档读取（剧本为 .docx/.doc/.pdf 等文件时）

- 用户提供文档路径、或把文档放进工作区时，先调用 skill 加载 `read-office-docs` 技能，按其方法（docx/pptx/xlsx 解包提取、doc/pdf 用 Word COM）把文档提取为纯文本，再进行下方剧本诊断。
- 提取结果直接作为剧本内容纳入诊断；提取失败（加密/扫描件/引擎缺失）时如实告知用户，并提供替代方案（请用户另存为 .txt/.md 或直接粘贴文本）。

## 1. 剧本诊断协议

对剧本（整部或单集）按以下清单输出紧凑诊断，逐项给结论，不写空话：

1. **题材定位**：品类（女频虐渣/男频逆袭/悬疑/甜宠…）+ 对标爆款框架
2. **目标受众**：年龄段 + 性别 + 核心情绪需求
3. **核心卖点/钩子**：前 3 秒画面与声音设计是否锁屏；全片传播金句单独标出
4. **节奏与信息点密度**：是否每 5–10 秒一个信息点/反转
5. **情绪曲线**：爽点/虐点/反转的排布与强度
6. **集末悬念与付费点**：卡点位置与钩子有效性
7. **角色弧光**：每个主要角色的起→变→终
8. **台词精简度**：单句 12–15 字为宜，过长的句子给出拆分建议
9. **修改建议**：按优先级（高/中/低）排列，每条可执行、可落镜

输出纪律：诊断紧凑；识别出的金句、付费点、切片素材单独用醒目标记。**剧情约束：诊断与修改建议只优化「呈现方式、节奏、镜头表达」，绝不修改剧情内核——台词、情节走向、人物设定、时间线一律以原剧本为准（用户要求：不许修改剧情，所有内容围绕剧情展开）。**

## 2. 人物档案卡标准（characters.md 条目）

```markdown
## <角色名>
- 定位：主角/反派/配角；作用（推进剧情/制造冲突/情绪锚点）
- 外貌：年龄、身高体型、发型、五官特征、标志性配饰
- 气质与性格：核心性格、情绪底色、口头禅、行为习惯
- 动机与弧光：想要什么、恐惧什么、结局变化
- 造型：常服/特定场景服装（固定描述词来源）
- canonical 描述词：<30–60 字，供 Seedance 复用>
- 参考图/首帧建议：<有/无；建议拍摄要点>
- 表演要点：微表情、肢体习惯、语气节奏
- 关系：与 <其他角色> 的关系
- 确认状态：待确认/已确认
```

**canonical 描述词规则**（一致性关键）：
- 结构 = 外貌 + 服装 + 气质，30–60 字
- 全项目所有镜头复用同一段；关键镜头用参考图/首帧锁定形象
- 外观未经用户确认前标注「待确认」，用户提供参考图或明确方向后立即修订

## 3. 关系网与一致性策略

- **关系网**：输出角色间关系 + 权力位阶（谁压谁、谁欠谁），供分镜设计站位与机位
- **一致性策略**：canonical 描述词全程复用；主角建议各出 1 张文生图参考图锁脸，后续图生视频/首尾帧引用

## 4. 记忆库读写（本技能负责）

- **记忆根解析**（每次会话检查一次）：环境变量 `SHORT_DRAMA_MEMORY` 非空且路径存在 → 用之；否则默认 `{{cwd}}/short-drama-memory/`。云端同步与复刻协议见记忆根内 `REPLICATE.md`。
- **会话开始**：先读 `MEMORY.md` 恢复上下文（用户偏好、项目清单、经验速览）；能判断项目时再读 `projects/<项目名>.md`。
- **本技能负责写入**：`characters.md`（新增/修订角色）；`projects/<项目名>.md` 的「剧本诊断 + 人物」部分。
- **新项目建档**：复制 `projects/_TEMPLATE.md` 为 `projects/<项目名>.md`，按模板结构填充——第 1 章完整产出，第 2/3 章留占位，模块地图状态同步更新。
- **用户纠正**：立即记入 `lessons.md` 与 `MEMORY.md` 偏好区，并在后续输出中遵守。
- **纪律**：只记录事实与用户确认的偏好，绝不编造；文件不存在用 `write` 创建，存在用 `edit` 增量更新；`MEMORY.md` 保持精简（索引+偏好），正文放子文件。
