# 轴线法则与高级越轴方法库

本库完整保存导演确认的180度法则、合法越轴方法和主动越轴叙事技法。默认准则是禁止无目的、无缓冲的随意越轴；越轴不是普通机位变化，而是需要明确设计、承接和复核的空间事件。

## 一、核心定义与默认红线

### 三类核心轴线

1. **关系轴线／对话轴线**：两个或多个核心人物之间的假想连线，决定对话、对峙中的左右位置和视线方向。
2. **运动轴线**：人物、车辆、抛掷物或其他主体的主要运动方向，决定动作、追逐和交通镜头中的前后与行进方向。
3. **方向轴线**：单个人物的视线、身体正面或明确目标方向形成的隐性轴线，决定单人镜头的朝向一致性。

### 180度法则

- 默认把摄影机限制在当前主轴同一侧的180度半圆内。只要机位保持同侧，人物朝向、左右位置、视线对接和运动方向就能保持一致。
- 摄影机越到轴线另一侧，会使人物朝向反转、左右位置颠倒或运动方向反向。若没有叙事目的与空间解释，这属于基础连续性错误。
- 每个对话、动作或群像叙事单元先确定当前主轴、机位所在侧、人物左右关系与允许的运动方向。主轴随人物真实换位、目标改变或群体行动变化时更新，但不能在画外无依据漂移。

### 必须守轴的场景

- 新场景尚未用全景或等效空间基准镜头完整建立人物站位、空间格局与主轴前，不得越轴。
- 日常双人交流、平稳正反打、生活化叙事和抒情段落默认严格守轴，确保视线相对，不能让双方无意看向同一方向。
- 连贯动作、奔跑、格斗、车辆行驶和高速追逐默认保持运动轴同侧；无缓冲反向会让观众误判前后与目标位置。
- 会议室、餐桌等站位明确的群像场景，以核心关系轴为稳定基准；不得因轮流反应频繁换侧。
- 无叙事目的、无可见动作、无中性缓冲、无连续机位运动、无空间重建的越轴一律禁止。

## 二、合法越轴的工业级方法

合法越轴的共同条件是：先明确越轴目的，再让观众看见或理解方向变化的理由。正式设计记录旧轴侧、新轴侧、触发点、所用方法、硬切锚点与重建立镜头。

### 1. 骑轴中性镜头

- 在轴线正上方的0度／180度位置建立正面或背面中性构图，使人物没有明显左右朝向，再直接硬切到另一轴侧。
- 适用于双人对话、正面对峙和人物直视镜头的段落。
- 中性镜头必须有原文、对白或动作承载，不能只为技术过轴添加无信息镜头。

### 2. 动作支点越轴

- 在人物转身、转头、起身、弯腰、换位、挥臂、武器挥过、身体或物体经过前景等改变朝向或遮挡关系的动作峰值完成直接硬切。
- 下一镜从同一动作方向、同一阶段或紧接阶段起幅，不能让人物复位后重新动作。
- 适用于调度丰富的对话、日常动作、近身格斗和人物换位。遮挡只是硬切匹配点，不生成连续遮挡转场。

### 3. 摄影机连续运动越轴

- 通过横移、环绕或跟拍，让摄影机在同一连续镜头中从轴线一侧移动到另一侧；观众必须看见机位跨越过程和人物关系如何改变。
- 适用于长镜头、群像调度、大空间展示和跟拍。运镜写清起幅轴侧、靠近骑轴、实际跨轴、背景视差变化与新轴侧落幅。
- 连续运动越轴本身无剪辑，镜长仍须服从普通镜头4秒硬上限；只有本集唯一高潮镜头可按时长模块例外处理。

### 4. 特写或空镜缓冲越轴

- 越轴前插入1–2个无明确左右方向的脸部大特写、物件特写、环境空镜或细节镜头，暂时弱化原轴方向，再硬切到另一侧。
- 适用于情绪转折、心理戏和时空转换。缓冲镜头必须由对应旁白、对白或画外连续对白承载，并提供新的情绪、信息或状态。
- 缓冲不能代替新轴侧的空间重建；越轴后仍须在1–2镜内给出明确空间锚点。

### 5. 全景重建立越轴

- 人物大范围调度、场景结构变化或大空间群像需要换侧时，越轴后立即用全景重新交代人物站位、参照物、行动方向与新关系轴。
- 全景既可作为越轴后的第一镜，也可在中性或动作支点后作为第二镜；必须让观众清楚确认左右关系，而不是只展示环境。

### 6. 人物真实换位越轴

- 人物在画面中通过可见走位实际交换左右位置，摄影机随后切换轴侧，是对新空间关系的还原，不是无依据的方向反转。
- 适用于走动式对话、会议室调度和多人场景。前镜必须让观众看见换位过程或关键阶段，下一镜继承新位置。

### 7. 渐变式多步越轴

- 用3–4个有效镜头逐步接近骑轴位置，再进入另一侧；每镜机位可偏移约15–30度，并通过共同主体、动作、视线或构图重心连续承接。
- 适用于长段落对话和持续场景调度。每一步必须产生新的叙事信息，不能为了隐藏越轴堆积无效机位。
- 也可以把多步变化组织在一个连续运镜中；若分镜执行，每一步之间仍是明确硬切。

## 三、分场景越轴规则

### 双人对话与对峙

- 常规交流严格守关系轴，正反打保持同侧和准确视线对接。
- 话语权、地位或控制权发生反转时，可由人物起身、换位、靠近、退开或摄影机连续运动完成越轴，使强势方的画面侧别和视线方向整体反转。
- 冷战、分手、鸡同鸭讲或心理隔阂可使用轻微或主动越轴，让双方视线不再精准对接，甚至有意看向同一方向；必须确认这是沟通失效的叙事表达，而非误设机位。

### 动作、追逐与格斗

- 追逐以整体运动方向为主轴。人物转弯、掉头或目标方向真实改变时，借动作支点或全景重建立换轴。
- 近身缠斗、换位和转身可多次使用动作支点改变轴侧，但每次都要保留敌我位置、受力方向和动作阶段；不能因快速剪辑失去空间锚点。
- 爆炸、撞击、Jump Scare或动作高潮允许以景别跨级加无缓冲越轴制造瞬间冲击；仅限明确高潮，且必须在随后1–2镜内重新锚定空间。

### 多人群像

- 存在核心对话时，以核心两人的关系轴为主；次要人物可在不改变核心左右关系的范围内形成局部方向轴。
- 环形站位可用摄影机连续环绕自然跨轴，也可用中间人物的中性镜头分步切换。
- 群像整体移动时，以群体主要运动方向为运动轴；个体短暂偏离不自动构成越轴，除非它改变了观众对整体方向的判断。

### 心理、回忆与虚幻

- 人物精神崩溃、认知颠覆或世界观崩塌时，可故意无缓冲越轴，让空间错位对应心理失序；轻微手持、景别跳级或方向反转必须共同落在同一情绪触发点。
- 回忆、幻觉、梦境和平行时空可比现实更自由地越轴，以方向差异标识非现实属性；进入与离开这些时空时仍须写清触发、边界与现实空间重建。

## 四、主动越轴的叙事技法

主动越轴本身就是表达内容，不能同时假装它没有发生。

1. **疏离与荒诞**：对话中突然越轴，使双方视线逻辑断裂或朝向同一侧，制造沟通失效、人物异化、黑色幽默或上帝视角的审视感。
2. **权力关系反转**：随着话语权转移，通过人物调度、连续运镜或动作支点越轴，让强势方从画面一侧转到另一侧，用空间语言完成地位颠覆。
3. **跳轴冲击**：剧情反转、惊吓点或动作高潮同时使用景别跨级与无缓冲越轴，形成景别落差和方位错位的双重冲击；随后必须重建空间。
4. **沟通错位**：夫妻冷战、分手或对话失效时，主动破坏精准视线对接，借左右关系变化表现心理裂痕。
5. **现实与虚幻区分**：现实段守轴，回忆、幻觉、梦境或平行时空主动换轴，以空间方向差异提示时空属性。
6. **心理失序**：重大打击或精神失常时，越轴与倾斜构图、手持或景别割裂协同，让观众感到方向基础被破坏。

案例名称只作为技法来源索引：可从《闪灵》的关系异化、《教父》的权力转移、惊悚片Jump Scare的跳轴冲击和《罗马》的渐变机位变化中理解方法；不得复制具体镜头或让案例覆盖当前原文与项目风格。

## 五、越轴红线与创作分寸

1. 观众尚未建立完整空间认知前绝对不能越轴；有意隐藏空间时也必须先建立当前可知范围和主体方向。
2. 日常叙事、生活化场景和平缓情绪尽量不用主动越轴；默认守轴是常态。
3. 每次越轴必须有明确叙事或情绪目的。仅为展示机位、增加变化或追求“高级感”的越轴属于失败。
4. 越轴后必须在1–2个镜头内用全景、固定参照物、人物真实换位结果或连续摄影机路径重新锚定空间。
5. 同一场景内无特殊目的的越轴不宜超过1次。再次越轴必须对应新的重大关系、动作、时空或心理变化，并重新执行目的与锚定检查。
6. 主动无缓冲越轴只用于明确的心理崩塌、权力颠覆、惊吓、高潮、沟通失效、现实／虚幻区分或荒诞疏离；其他场景必须使用工业级缓冲方法。

## 六、逐镜设计与交付检查

- 列镜头前建立轴线表：当前主轴类型、轴线两端、摄影机所在侧、人物左右／视线／运动方向、轴线何时因真实动作发生变化。
- 每镜起幅继承前镜轴侧与方向；落幅记录机位侧别、人物朝向、视线、运动方向和下一镜承接锚点。
- 计划越轴时，在实际发生越轴的镜头描述中写明“越轴目的 → 越轴方法 → 触发动作或中性缓冲 → 新轴侧 → 1–2镜内空间重锚”；初始空间状态只记录起始关系轴与摄影机所在侧。
- 未计划越轴时，镜头机位全部保持当前主轴同侧；不同焦距、景别和高度不等于换轴。
- 定稿时连续审看片段，检查是否出现人物左右互换、双方看向同一方向、车辆或奔跑方向反转、动作受力方向改变、群像站位漂移等意外越轴症状。
- 有意越轴必须在制作参考和检查报告中标注目的与方法；没有标注而发生的方向反转按意外越轴处理并修正。
