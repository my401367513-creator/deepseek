# 大型仪式、等级与特效递进库

仅在原剧情存在仪式、测试、觉醒、召唤、能力等级或同类特效递进时加载；不得把奇幻、科幻或大场面规则套入普通现实项目。

## 空间阵列锁定

- 首镜前集中记录中心物、环绕物、前后左右、高低层级、入口、观礼区和关键人物的初始位置与朝向；数量、名称和方位一一对应。
- 先用具有明确起幅、揭示路径和落幅的空间基准镜头建立阵列，可使用推进、侧移、升降、环绕、俯冲或高位角度逐层交代关系；再进入局部。以最有表现力且能清楚揭示阵列关系的路径为准，不进行生成稳定性评估；后续只改变原剧情明确启动、移动或损坏的对象，其余保持方位、距离和高度。
- 每镜写清主体相对中心物和相邻锚点的位置。超广角俯冲、环绕和细节展示不得在同一短镜中同时承担。

## 抽象等级视觉化

- 等级、价值或能量强弱使用项目确认的稳定映射。颜色不能成为唯一依据；从亮度、作用范围、形体尺度、运动速度、环境影响或群体反应中选择必要维度形成可观察差异。
- 同一等级复用同一组视觉规则；相邻等级只增加原剧情支持的差异，并保留共同测量锚点以便直接比较。
- 不写“数百万／数亿粒子”等不可验证数量，也不依赖“顶级、史诗、震撼”等抽象词；改写为密度、覆盖范围、运动路径、照明范围和具体物理反馈。

## 特效变化链

- 按“初始静止状态 → 明确触发源 → 传播或汇聚路径 → 可见形态或结果 → 对人物／道具／环境的必要物理影响 → 衰减结束状态”设计，只保留原剧情需要的节点。
- 一个短镜只突出一个主要状态变化。多个节点无法自然完成时，在发光稳定、形态完成、冲击到达或开始消散等清楚落点硬切拆镜，不靠加速塞入。
- 光与能量写清来源、方向、作用对象和结束位置。衣料、头发、尘土、阴影或地面反馈每镜只选最能证明力量的一项，避免全部同时爆发。

## 同类事件递进

- 连续展示同类测试或仪式时，保留相近构图、中心物尺度和观察角度作为比较基准，再按原剧情逐级改变能量、形态、空间影响和人物反应。
- 群体反应按等级分层：背景群体统一且克制，只有剧情指定的关键人物获得清晰反应；每一级只增加一个主要变化。
- 同一句旁白可覆盖多个对比镜头，但制作参考只标明一次原句和覆盖范围，不重复播放或改写。

## 失败条件

方位漂移、等级映射失效、不可验证粒子数量、单镜堆叠多个特效阶段、全员同步夸张反应或重复旁白均视为不可交付，须先修正。
