# 镜长与生成段模块

本模块是镜头时长、按工具选择生成段边界、核算和长镜头报告的唯一规则源。正式音频状态由 `audio-timeline.md` 提供。

## TIM-01 视觉节点与执行时长

- 故事画面和首次镜头构思阶段不预设平均镜长或统一单镜硬上限。先按语义、动作、情绪和信息转折划分视觉节点；相邻节点若能由同一条连续摄影机路径和画内调度完整承载，可以保留长镜头，否则在自然落点切换观察对象、景别、机位、焦点、空间关系或运动状态。
- 不得让同一主体以同一景别、同一构图和同一观察关系跨越多个独立视觉节点而没有新的可见变化。旁白或对白持续时，固定机位可以保留，但必须有足够的表演、画内调度、道具变化或注意力转移；纯静止背景不能填满长文本。
- 视频提示词与剪辑执行阶段，以正式旁白／对白音频的实测总时长为外边界，再按视觉节点分配镜头时间；音频未到位时只能标记“暂估，待正式音频锁定”，不得用字数或固定语速伪造锁时。
- 进入最终执行核算后，若项目采用本技能默认节奏标尺，全片平均镜头时长控制在2.5–3.5秒，普通镜头最长不超过4秒；5–6秒高潮镜头是每集最多1处的例外，必须承载本集明确高潮并具有持续的动作、情绪、信息或构图变化。该标尺不得在故事画面阶段反向制造切镜。
- 对白总时长不设上限；长对白按自然语速、停顿、语义节点和倾听反应安排画面，可使用说话者、倾听者、动作、道具、空间或画外连续对白承载，不能仅为填满声音让同一角色保持单一说话画面。

## TIM-VISUAL 镜长闭环与受控视觉余量

- 执行时区分四种时长：音频时长（旁白／对白的实际时间）、成片镜长（最终剪辑使用区间）、生成素材时长（原始视频，可含剪辑余量）和生成段时长（一次工具提交的任务时长）。生成素材余量与生成段边界不得反向延长成片镜长、修改固定旁白或截断人物对白。
- 每镜按“有效音频时间窗 → 视觉节点 → 主导叙事任务 → 观众必须先读懂的完整变化 → 最短完整时间 → 停留价值 → 最早有效切点”决定成片镜长。完整变化至少完成动作、情绪、关系、信息或悬念中的一项；在变化成立前切出属于承载不足，变化成立后没有新增价值属于停滞。
- 最短完整时间按观众辨认、动作完成、情绪积累、信息理解、空间建立和声音同步中实际最大的需要判断；不使用字数换算、固定语速或平均镜长作为创作起点。
- 镜头可以相对单一旁白或对白语义单元视觉提前或滞后，任一侧通常控制在约0–0.5秒。额外画面必须仍处在相邻有效旁白／连续对白的承载时间窗内，或与已确认的必要动作／环境声共同承载，并同时有结果、情绪余波或下一镜承接锚点；不得新增未经确认的事实、动作、结果或信息，不能形成只靠静默、拟音或环境声成立的独立镜头。视觉余量是受控承接，不是旁白音频延长。
- 整段有效音频结束后不得无依据追加静默、空镜或环境画面。确需尾部画面时，必须有已确认的对白或必要声音共同承担，且不能只靠该声音单独成立新镜头；或者有导演确认的音频空间，并纳入正式时间轴。超过约0.5秒的单节点余量按非典型镜头记录依据，不为指标压缩动作或情绪。
- 长镜头、高潮镜头、跨语义节点镜头或存在视觉余量时，制作参考记录“时间关系、视觉余量、承载依据和切出理由”；普通镜头可省略。生成素材可以带起势、收势和剪辑寻找余量，但不计入成片镜长。

## TIM-02 最终执行时长检查

- 仅在正式视频提示词与剪辑执行阶段核算全片平均镜头时长是否在2.5–3.5秒；逐镜确认所有非高潮镜头不超过4秒，5–6秒高潮镜头每集最多1处，并核对长旁白／长对白是否跨越了多个视觉节点却停留在同一主体、同一景别和同一构图。发现超限或停滞须记录镜头号、视觉节点、实际时长、拆分点和修正结果。

## TIM-03 生成段边界

- 单次生成边界由所选工具适配器决定；默认Seedance／即梦为4–30秒，其他工具使用导演提供的明确边界。故事段不等于生成段：时间、地点、人物时期、固定造型、身体拓扑或主要空间变化时默认建立新生成段。
- 只有工具明确支持、资产状态可独立锁定，且设计记录合并目的、状态切点、资产隔离方法、硬切锚点和结束状态时，才允许跨状态合并；缺少任一证明即拆段。分段依据是身份与状态连续性，不是按预期生成稳定性降低画面表现力。
- 每个生成段最多9个镜头。镜头设计完成后再按叙事单元、对白归属和连续性选择段界；第10镜不得进入同一生成段。
- 超过9镜时优先移动段界并增加生成段，不得为压缩镜头数强行合并独立信息、动作阶段、情绪转折或认知节点，也不得延长单镜掩盖复杂度。调整后每段仍须满足当前工具适配器的时长边界。
- 不把4–6秒短段作为默认方案。只有镜头上限、总时长、对白或动作完整性、连续性要求，或导演明确要求时进一步拆分。
- 分段只改变生成批次，不改变原文顺序、旁白／对白分类、剧情事实或信息边界。
- 同一段连续对白必须完整放在同一个生成段内，不得跨越两个生成段。该对白可在段内按自然语义停顿或动作触发硬切到说话者、倾听者、说话者动作或已有道具，并使用画外连续对白保持声音连续。
- 生成段边界不得落在词语、不可拆短语、连续对白或不可拆动作内部。先移动段界；若整段对白连同必要表演超过当前工具单段上限，则保持对白原句与声音连续，在导演确认具体生成方案前不得擅自截断或改写。

## TIM-LONG 长旁白与长对白覆盖

- 长文本先建立“视觉节点表”：`语义范围｜观众先读懂的可见变化｜动作／情绪／信息主体｜可合并的连续路径｜自然切点｜预计相对时长`。这张表用于故事画面和提示词之间的交接，不改写旁白、对白或其音频。
- 同一连续镜头只有在摄影机路径、人物调度、焦点、道具状态或空间关系持续产生可辨变化时，才可覆盖多个相邻节点；长镜头超过工具单次边界时，按动作阶段、认知落点或声音自然停顿拆成多个生成素材，并由硬切和状态快照承接。
- 长对白的声音可以跨硬切连续，但画面必须在语义落点、倾听反应、动作触发、信息揭示或关系重心变化处转移观察对象；说话者、倾听者、道具和空间不机械轮换，每次切换都须提供新信息或新关系。

## TIM-MONT 蒙太奇生成与剪辑

- 跨年龄、地点、固定造型或身体结构的蒙太奇，先建立统一蓝图，再按高风险状态或镜头组独立生成，最后用构图、动作、道具或声音锚点硬切组接；不让模型在单镜中用连续变形代替时期或场景切换。
- 蒙太奇蓝图记录：`段落目标｜旁白覆盖范围｜状态顺序｜每镜新增信息｜时期／地点／资产｜前镜落幅锚点｜后镜起幅兑现｜声音或动作接力｜预计成片镜长｜独立生成任务编号`。匹配硬切只锁定承担接力的主体位置、运动方向、手势阶段、道具重心或形状，不要求像素级复制。
- 单段内部多镜蒙太奇只用于人物时期、固定造型、身体拓扑、主要地点和光线状态保持一致的压缩段；每镜必须产生独立信息、结果、递进、对照或回收，并具有明确硬切锚点。
- 独立素材可长于成片使用区间，但只生成完成“进入动作 → 核心动作 → 稳定落点”所需的剪辑余量，不机械拉到工具最长时长。最终镜长按观众辨认动作、信息和结果所需的最短完整时间确定。
- 蒙太奇依次执行蓝图审核、单条素材审核和粗剪整体审核。尚无实际素材时只能判定蓝图与提示词状态，素材和粗剪保留“待生成后审核”；单镜均通过但组合后没有推进、匹配或结束状态，整体仍判定失败。

## TIM-04 时间核算

- 每段内部时间轴从0.0秒开始，允许小数；镜头连续、无空档、无重叠，时间范围合计必须等于段长。正式文本的镜头标题显示段内累计时间范围`<起始秒数>-<结束秒数>`，不显示镜头编号或“时长”字样；制作参考与可提交区保持一致。
- 正式旁白音频未到位时只能标记“暂估，待正式音频锁定”；收到完整旁白音频后按实测重建，不沿用旧估算冒充锁时。旁白音频中朗读的对白单独登记为替换位，不把该朗读时长或声音当作角色对白成片轨道。
- 分段完成后核对每句保留旁白、对白替换位、单独生成的同期对白和画外连续对白的承载范围，确保旁白与对白不重叠；对白按自然语气完整生成，若固定旁白与完整对白无法同时承载则登记冲突并暂停该段。
- 单一语义单元的视觉提前／滞后必须在相邻有效音频、连续对白或与必要声音共同承载的同一时间窗内完成；局部余量不得累积为段外或整集外的无声时长。生成段和整集的成片时间轴仍须按正式音频或导演确认的音频空间核算，镜头范围连续、无空档、无重叠。

## TIM-05 逐镜四层审查

结构合规不能替代画面有效性验证。完成分镜后必须脱离创作过程，逐镜按以下四层重新审查：

1. **语言承载量**：当前旁白或对白能否按自然语速、停顿和情绪在最终镜长内完成；长旁白／长对白是否已按可辨识语义节点获得足够且不同的画面，且未由同主体同景别同构图停滞承载。
2. **动作承载量**：镜内的准备、执行、接触、结果与收势能否按真实动作速度完成，并让关键阶段被观众看清。
3. **信息承载量**：镜内要求观众辨认的主体、道具状态、空间变化、反应和剧情结论是否超过同一构图能够清楚传达的数量。
4. **画面表现力**：景别、机位、调度、运镜、前后景、遮挡、背景动态和剪辑落点是否共同强化当前剧情重点，是否存在保守、平直、重复或视觉重心分散的问题。

四层均须逐镜得出结论；语言、动作或信息任一层超载，或画面表现力不足，即否决该镜头，不得因镜头数量正确、最终生成段时长合规或文字描述完整而标记通过。优先在自然动作、语义或认知落点拆镜；不可拆的连续动作或对白才调整镜长，并执行长镜头自审。画面表现力不足或长文本出现同配置停滞时重设景别、机位、调度、运镜、构图层次或剪辑落点，不以生成稳定性为由降级。修正后必须从第一层重新复核，不得只检查改动层。

视觉余量复核必须同时确认：它相对的是单一语义单元而非整段音频；额外画面仍由有效旁白／对白或与必要声音共同承载，且不是只靠声音的独立镜头；有结果或承接依据；没有新增事实、动作、结果或信息；生成素材余量没有被计入成片镜长；提前或滞后没有造成音频重叠、段外静默或下一镜状态断裂。

正式交付前至少列出所有被否决并已修正的镜头编号及原因；若检查从未否决任何镜头，也必须明确记录“四层逐镜复核完成”，不能只用镜头数量或时间计算代替审查。
